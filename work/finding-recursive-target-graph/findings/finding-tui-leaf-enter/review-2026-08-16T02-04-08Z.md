# W7 review — changes requested

Reviewed the W7 implementation against `FINDING.md` and `PLAN.md`, the v11
handoff at authority snapshot 39, and the focused real-PTY/parity tests.
Focused verification passed: 12 tests in `test_w7_split_pane.py` and
`test_parity.py`.

## R1 — Thread navigation silently stops at the first ten Threads

**Confirmed.** `Console._preview_threads()` calls the bounded
`projection.work_threads(..., limit=DISC_PAGE)` and discards `next_after`
(`src/baton_work/tui/app.py:330`). The preview's default-New selection and
focused `j`/`k` navigation operate only on those returned rows. Consequently,
a Work with more than ten Threads cannot reach Thread 11 or later from the
split pane, and a personal-New Thread beyond the first page is not selected
even though the ruling says the pane selects a Thread with personal `New` when
one exists. The header also reports `len(threads)` as the total
(`app.py:388`), so a truncated set can display an incorrect `Tn/10` total.

This contradicts the pinned requirement that multiple Threads remain
distinct and explicitly switchable, and the older bounded-navigation rule in
the same console that every Thread remains reachable. Preserve bounded reads,
but retain and navigate the continuation state (or otherwise provide a
bounded, complete selector model). Add a real-PTY regression with more than
`DISC_PAGE` Threads and personal New only on a later page.

## R2 — A short terminal can focus a pane that is not rendered

**Confirmed.** Rendering suppresses the split below `MIN_SPLIT_HEIGHT`
(`app.py:238`), but `handle()` accepts `Tab` in table mode at every height and
sets `focus = "msgs"` (`app.py:671`). On the next repaint the terminal still
shows only the Work table, while the focused-Msgs branch consumes `j`, `k`,
`n`, `p`, and `s` (`app.py:676`). The human therefore loses normal Work-row
navigation to an invisible pane until guessing `Esc`, Left, or Tab.

Short-terminal fallback is allowed, but it must not expose invisible focus or
silently reinterpret keys. Make focusability follow the rendered layout (or
provide a visible short-terminal interaction) and add a real-PTY regression
below `MIN_SPLIT_HEIGHT`.

## Disposition

Changes requested. W7 remains schema-14-safe and the core split-pane behavior
is otherwise aligned, but the two navigation gaps above must be corrected
before W7 can close or the serial same-schema plan can advance to W8.
