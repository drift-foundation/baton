## R1 — ownership transfer is enforced only for phase/classification

**Blocking correctness defect.** The new `_handler_gate` protects `classify`
and `set_phase`, but older workflow mutations still authorize by participation
or mere authority membership. After `@push.bug`, `push.sl` can pass or
terminally close Lang's Work even though `@` explicitly grants no mutation
authority and does not change Current. The additive regression at
`tests/work/test_phase.py:371` reproduces both commits.

This violates the confirmed simplification: delegation is `=>` ownership
transfer, and the former Current or an `@` respondent cannot continue acting
as Current. Apply one in-lock responsibility rule to workflow-state decisions,
not a phase-only rule. Plain discussion contribution, `+` attention, personal
seen state, and answering the exact obligation remain non-owner operations.
At minimum the pass/Next and terminal-close paths must use the current handler
gate and record its snapshot. Before widening further, pin the complete matrix
for request creation, dependency changes, parent/child creation, obligation
disposition, and reopen so participation is never accidentally treated as
ownership again.

## R2 — JSON omits the new available transitions

**Blocking machine-interface defect.** `projection.detail` promises the
explicit transitions available to the participant, but never reports
`classify` or `set_phase`. The additive regression at
`tests/work/test_phase.py:395` fails for the Current handler and also pins that
authority follows `=>`. Agents must not discover operations by attempting
them. Compute availability from the same live route/handler rule as the
authority, including phase-specific restrictions, without making the
projection a writer.

## R3 — the parked count is not in the top-level JSON view

**UX/parity defect.** The TUI header always calls `team_summary` and paints
`[park:N]`, while the JSON `home` result remains only a list of rows. A separate
optional `summary` command does not put parked Work “in our faces” for agents
entering through the top-level view. Make the canonical top-level JSON
projection carry its summary (and have the TUI consume that same projection),
then pin the common shape with parity evidence. Do not maintain two calls that
can be sampled at different snapshot sequences.
