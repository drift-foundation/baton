What was NOT run this round, and why
------------------------------------

The review is explicit: "Focused tests suffice; do not repeat broad
environment-dependent suites merely as insurance for this small correction."
So the three package-surface sweeps and the whole tests/manager discovery were
NOT repeated. evidence/claim-362249/ holds them against this same base commit
with byte-identical base/candidate failure lists, and this round changes no
behaviour those suites reach — it adds one validator and one export name.
tests/tools was likewise not repeated; evidence/claim-361943/ records that
surface against the same base.

No provider, no container engine, no Authority, no installed instance, no
deployment. The Job stores the cases open are the disposable SQLite files
tests/job_manager/fixtures.JobManagerCase creates under a temporary directory.
The compatibility generation is moved with unittest.mock.patch in the test
process only, as in both earlier rounds and as the reviewer's probes do; no
installed default, configuration file or live instance is touched. No Git
operation of any kind, in the repository or in the scratch root.
