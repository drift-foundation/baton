the second integrity traversal skips symlinks before comparing the recorded
fingerprint. Replacing a previously checked regular file with a symlink leaves

The proof returns and `establish_line_access` grants root mode 02775.

The deterministic reproduction replaces the first visited file while opening
its second sibling. The historical `_provision_line_access` from HEAD refuses
with `an initial development-line entry changed before provisioning` and leaves

control succeeds. This is a regression in the preserved pre-grant invariant,
not a request to establish general atomicity against arbitrary writers. The
outside sentinel is unchanged in both versions; no outside read/write exploit
or live production race is claimed.

**Required:** account for the previously recorded entry when the second pass
observes a symlink, so a regular-file/directory-to-symlink transition cannot
bypass revalidation. Preserve legitimate stable symlinks, no-follow behavior,
depth-bounded descriptors, and root-only permission setup. Add this interleaving
and its stable-symlink/control coverage. Do not restore held descriptors per

first preparation path in `review_cycles.create_line`, before the improved

identify the inaccessible entry. The owner explicitly retained actionable

information and honest ungranted state. Apply the existing access diagnostic
