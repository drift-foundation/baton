## P2 — optional public preloads can replace owned stored evidence

`settlement_of(..., intent=...)` trusts a supplied dictionary instead of
proving the stored intent exists. The probe stores only an orphan settlement:
the ordinary reader raises ContractRefusal, but passing a fabricated matching
intent returns the settlement while `intent_of` still returns None.

Similarly, `_stage_row` returns a supplied `stage` unchanged. A stored intent
that names the wrong Work refuses through ordinary `intent_of`; supplying a
stage dictionary with that same wrong Work makes the public reader return it.
This is a bypass in the new optional reader interface, not evidence that a
current production caller fabricates either operand. Merely matching a supplied
document's members cannot prove that this store owns it.

Required correction: public readers must establish the same owned result with
and without optional arguments. Revalidate the actual records or keep trusted
reuse inside a private owner-controlled path whose public entry performs the
ownership checks. Do not use arbitrary caller dictionaries as proof. Add
controls for the orphan-intent and false-stage preloads alongside honest
reuse. The optimization's claimed single moment is also not established by
passing ordinary dictionaries; do not claim a transactional snapshot it does
not provide.
