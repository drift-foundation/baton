## Accepted correction — exact reachable causal vector

`worker_manager.exchange._caused` now composes and compares the whole reachable
state map rather than checking selected members:

- `answered` requires every commanded operation to be answered;
- `faulted` requires the answered prefix, the next operation faulted, and no
  later state; and
- `lost` requires a non-complete answered prefix, permits only the next
  operation's optional `dispatched` state, and permits neither a fault nor any
  later operation.

The optional lost slot correctly covers both process-death windows: before the
next dispatch event and after dispatch but before its answer. It does not admit
another state at that slot. Receipt enforcement and exact schema, correlation,
member, vocabulary, digest, and durable-secret checks remain ahead of this
comparison. The implementation therefore refuses the four contradictions from
pass 3 without rejecting legitimate fault and loss boundaries.

The candidate `FINDING.md` explicitly marks the prior weak tail clause
superseded in place and records the replacement exact-vector decision, so the
chronological history and current rule agree.
