## R1 — recoverable partial staging becomes a permanent hold (high)

**Confirmed.** In context_delivery.py:189, `_write` creates the final staging
filename before its write loop finishes. If the process dies after a short write,
retry finds that filename with a prefix of the expected bytes. The existing-file
branch at line194 refuses it. provider_context.py:495 then converts that custody
refusal into a durable `custody-invalid` hold, which blocks later finalization.

`reproduce-175073.py::ReviewProbes.test_partial_state_write_retry` cuts after three
real bytes of the first staged state write. It uses the selected real owner
fixture, with valid receipt, excluded runtime and unchanged original HOME. The
first call leaves status `admitted`; retry refuses `existing custody file differs`
and leaves status `held`, reason `custody-invalid`. Runtime start count remains1.
The probe asserts this observed defect; its passing result is not acceptance of
the behavior. The existing staging-cut test interrupts before the manifest write,
after complete state writes, and therefore misses this case.

Accepted DESIGN section7 explicitly requires incomplete generation staging with
valid receipt/exclusion to resume only its custody operation from the same pins
and bytes. This crash prevents healthy correction/restart despite all source
facts remaining available. It is a slice A recovery defect, not deferred B work.

**Required correction:** make interrupted writes recoverable within positively
identified, owned, uncommitted staging, revalidating original source and runtime
exclusion. Preserve refusal for mismatching published/committed generations and
foreign custody; do not broadly overwrite existing files or erase uncertainty.
Cover cuts inside state, identity and manifest writes, including before the first
byte and after partial progress. Prove retry finalizes once, preserves the exact
bytes and witness, and does not start a provider/runtime again. The implementing
owner chooses the bounded staging protocol; no architecture restart is requested.
