- `bind_context_invocation(control, jobs, authority, *, attempt_id, writer_id, profile_digest, task_bytes)` derives and commits the serving binding after admitted use/delivery. It resolves the original assignment/Job, retained input and task contract, source/writer/profile, exact task byte digest, canonical implementation prompt digest, expected argv digest and deterministic invocation ID.
