`delegation._refreshed` says its answer carries exactly one member, but lines
708-724 accept any `isinstance(answer, dict)`, read it through its own `.get`,
and silently discard every undeclared member. This is not the closed documented
result shape required by the previous review.

A direct probe against the proposal overlay showed both failures:

- `{"execution_runtime": "quiescent", "unexpected": 1}` was accepted and
  reduced to `{"execution_runtime": "quiescent"}`;
- a `dict` subclass whose `.get()` raises executed that override and propagated
  `RuntimeError` from the purported validation boundary.

contract: an owned exact built-in document with an explicit member set. The
refresh seam needs the equivalent property, followed by validation of the
closed runtime vocabulary. Add regressions for an extra member and a mapping
subclass, in addition to the scalar/missing/invalid-value cases already present.

### P1 — arbitrary implementation defects are blanket-caught and can be lost

`manager._refresh` lines 421-440 literally catch `Exception` and turn every
unexpected defect into a per-tick `refresh-fault` detail. This contradicts the
previous review's explicit requirement: operational engine-boundary failures
need a typed, per-stage uncertain outcome, but arbitrary implementation defects
must not be blanket-caught.

The candidate's disclosure argument does not hold for the serving path.
`manager.serve` lines 651-655 overwrites `report` on each tick and returns only
the final report. A programming defect caught on an earlier tick is therefore
neither raised nor durably recorded and can disappear completely on the next
successful tick. The new tests at `test_sweep.py:391` and `:417` encode this
silent-loss behavior by requiring an arbitrary `RuntimeError` to be contained.

Keep stage isolation for **typed expected operational failures** and malformed
provider evidence. Translate known engine failures at the deployment seam into
a dedicated typed condition/result, then catch only that condition and
`ContractRefusal` in the manager. For example, the current subprocess runner
can raise `subprocess.TimeoutExpired`, which is an expected engine reachability
case but is not an `OSError`; it currently reaches the generic branch. Add
separate proofs that a typed engine failure is uncertain and does not suppress
another stage or readable exchange, while an arbitrary implementation
`RuntimeError` escapes instead of being converted into transient report data.
