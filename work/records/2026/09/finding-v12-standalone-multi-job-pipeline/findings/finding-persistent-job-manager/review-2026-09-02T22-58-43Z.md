## Blocking findings

### P1 — restart adoption can bind one store's canonical offer to another store's intent

`job_manager/submission.py` derives `offer_id` from only `job_id` and stage
kind. `job_manager/manager.py::_adopt` then treats a Worker Manager operation
row with that derived id as this stage's act without comparing its signature
or persisted offer facts to the submitted Work, input, policy, and profile.
The CLI independently selects `--store` and `--control`, with no durable pairing
between them.

Measured reproduction: create Job store A and Job store B over one control
store; submit `job-a/implementation` in each with different input digests;
sweep A, then sweep B. B reports `[admit, adopted]` and projects its own second
digest, while the canonical `offer.issue:offer:job-a/implementation` signature
contains the first digest and not the second. The same operation id has become
two different accounts of intent.

Correction acceptance:

- A manager can adopt a canonical operation only after proving it is the exact
  act for this persisted Job/stage intent, or the two stores are durably paired
  and the operation namespace is unambiguous by construction.
- A mismatched existing canonical operation refuses explicitly; it is never
  recorded as `adopted` and never projected beside the new intent.
- Add a real-store restart regression plus the two-Job-store/one-control-store
  collision regression. Keep the ordinary performed-but-unrecorded adoption
  path working.

### P1 — bounded test-change authority accepts paths outside its grammar

`job_manager/documents.py:231-239` says `test_scope` contains
repository-relative paths but validates each entry only as non-empty text. The
candidate accepted `../outside.py`, `/absolute.py`, and `v12//dup.py` unchanged.
Because this value is the durable authority later review and integration use,
this is not cosmetic input tolerance.

Correction acceptance:

- Apply the existing public normalized POSIX-relative path contract to every
  scope entry.
- Refuse duplicate entries so one scope set has one durable spelling.
- Add traversal, absolute, empty/dot segment, backslash, NUL, and duplicate
  regressions, plus the existing positive and empty-scope cases.
