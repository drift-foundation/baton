indexes by name, uniqueness, origin and column list. It does not compare an

schema validation, and the exact safety rule enforced by
`episodes_one_live_per_stage` can be reversed without detection.

The retained `repro-2026-09-05T11-56-00Z.py` replaces the schema-3 index with

The current build migrates the store to schema 4; the regression expecting a
fail-closed `ContractRefusal` fails. The correction suite covers a missing
index and an added column, but not the changed constraint required by the
previous review.

and table constraints before running 3 -> 4. `sqlite_schema.sql` is available
even where no dedicated CHECK pragma exists; legitimate installed and migrated
