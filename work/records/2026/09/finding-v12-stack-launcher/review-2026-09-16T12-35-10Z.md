## K1 — selector paths can control another instance (high)

`instance.malformed` requires absolute paths but does not compare them to
`layout(destination)`. `read` compares only the selector parent with destination;
`verify` checks only that destination's distro; `settings` and `stack.main` then
trust the independent state/store/config/log fields.

Confirmed reproduction: leave A's selector in A with A's destination and valid
runtime digest, replace state/logs/job_store/control_store/deployment with B's
paths, call stack.main --instance A/instance.json stop. It returns zero and
dispatches stop to **B/state**. Stop was substituted to capture the target;
no signal was sent. This is the cross-control path the owner explicitly forbids.

Derive paths from one validated canonical destination, or require every stored
path to match that derivation before use. Validate authority/deployment binding
and canonical resolved containment; refuse path alias/symlink escapes and foreign
stores/process roots before reads with effects or process control. Type-check
fields too: state=17 currently leaks TypeError instead of InstanceRefusal.
Cover same-location edited selectors, not just selectors copied between roots.

## K2 — verified runtime differs from executed/runtime-reachable code (high)

Two independent gaps:

1. `stack.instance_settings` verifies B/distro, but manager_argv delegates to
   the currently executing command. With frozen execution simulated at A and
   a valid B selector for a DIFFERENT runtime digest, the generated child is
   A/distro/baton-v12-stack. B's recorded command is never selected or checked.
   Byte-identical copies are a useful positive case but do not prove this
   mismatching-build refusal. Dispatch to the selected installed entry point
   with an integrity check, or refuse incompatible running-vs-selected runtime
   before lifecycle execution. Source recipes must likewise execute installed
   code rather than merely select its stores.
2. `manifest` hashes symlink text without rejecting targets outside the bundle.
   A/library.so pointing to mutable material outside distro is accepted. Change
   the target bytes: the manifest is identical and verify still succeeds.
   Safe internal links may be supported, but reject escaping/absolute external,
   broken and unresolved links and unsupported file types; retain whole-bundle
   coverage of actual code/resources. Bootstrap copytree(symlinks=True) preserves
   this problem. Also validate the distro root itself and relevant modes/types.

The positive control confirms direct regular runtime-byte changes ARE refused;
that improvement does not cover these two paths. Reproductions simulate a
frozen executable for argv only and use real scratch files for symlink changes;
no claim of an actual foreign binary launch is made.

`bootstrap.main` calls prepare before install checks the distro/destination
runtime. With a missing distro, a substituted prepare is invoked first, then
install returns refusal. Real prepare composes Authority state and publishes
records/configuration. The new install requirements must join preflight before
those effects, not follow them.

Direct install on a destination with an existing corrupt instance.json but no
distro replaces that selector. The reproduction uses real scratch files and
substitutes only the identity query. Existing runtime is one custody condition,
not the complete existing-instance state. Refuse uncertain/partial/corrupt
state before any replacement, preserve existing bytes, and make partial failure
recovery explicit without turning this into a migration feature.

`_identity_of` accepts any JSON with exit zero, including frozen=false plus
schema_assets='FileNotFoundError: absent' and native_rpds='ImportError: absent'.
Install publishes that identity into a selector. The earlier review explicitly
required meaningful identity/resource validation. Validate its structure,
frozen/runtime compatibility and successful required resource checks before
publishing or composing. A manifest proves preservation of whatever was copied,
not that the initial contents are a functioning selected bundle.

Regression scope: missing/invalid distro, unusable identity/resources, existing
selector without distro, incomplete/corrupt state and repeated bootstrap must
leave durable state untouched on refusal. Simulated ordering check is not an
Authority mutation test; add focused actual-path coverage within authorized
fixture boundaries.
