`released(found["owned_id"] or name, ...)`. Before the late inspection assigns
owned_id, an exception therefore stops/removes whatever currently has the name.

container wins the name between preflight and docker run, this run fails but
its finally removes the winner. Even the normal inspection path adopts the
ID returned for the name without proving that this invocation created it.
