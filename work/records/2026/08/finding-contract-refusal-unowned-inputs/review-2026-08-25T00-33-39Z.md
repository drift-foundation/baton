## [P1] The confirmed message bound is not enforced

`ContractRefusal.__init__` now establishes exact built-in text and UTF-8
encodability, but accepts text of any length. That is not the dossier's
confirmed “encodable, bounded durable text” contract, and it violates the
acceptance that unbounded message input cannot escape to later storage or
logging.

The additive
`test_a_message_cannot_be_an_unbounded_durable_value` constructs a public
100,000-character message and requires the build-time assertion used by the
other constructor-owned inputs. It fails because the constructor accepts the
value. The dossier does not yet name the numeric maximum, so that exact bound
must be ruled and pinned before implementation.
