# Independent review — first negative/race slice

This is not signoff for W32382. The plan-rejected and provider-unresolved
cases are useful partial evidence, but four acceptance gaps remain.

## Accepted partial evidence

- An expired offer reaches `settlement-expired`; activation and start refuse
  before any engine call, and the daemon carries no matching container.
- `plan-rejected` crosses the production output, credential and launch
  providers, publishes no completion envelope, and reaches force-removal,
  daemon-observed absence, provider teardown and clean settlement.
- A real container can be absent while an unresolved launch ending keeps
  cleanup pending; a later retry settles only after the provider can answer.

The last case establishes settlement ordering. It does not by itself establish
lane reuse, which is a separate acceptance statement below.

## [P1] The post-create-failure case injects no failure

`test_a_post_create_failure_converges_without_a_duplicate` performs one
ordinary successful `request_runtime_start`, then verifies a second start is
refused and two reconciliations retain the same identity. That is useful
duplicate-start coverage, but the adapter never creates a container and then
fails on the way back. The failed-start settlement/reconciliation boundary is
therefore not exercised.

`evidence/w32382-review-post-create-shape.py` records the two calls: the first
is bare and successful; only the second is under `assertRaises`, after the
attempt already owns a runtime. Wrap the real engine answer so the container is
created but the start call faults/refuses, then prove the manager attaches that
exact runtime, starts no replacement on retry, and eventually removes it
through the ordinary cleanup crossing.

## [P1] The required unsupported-version and deadline endings have no seam

The implementer correctly did not alias `unsupported-version` into the frozen
worker-disposition axis. But that does not satisfy the Work: a handshake
refusal can occur after the execution container exists, and the carried
attempt-domain invariant explicitly includes failure and deadline. The current
tree has no composition from either handshake refusal or the manager-owned
deadline observation into runtime cleanup.

Record these as missing production composition seams and implement them here,
or decompose them into bound Work that gates W32382. They cannot be omitted and
then described as four of five endings complete. `unsupported-version` must
remain a typed handshake refusal; deadline needs one explicitly owned runtime
meaning rather than borrowing interrogation prose.

## [P1] Lane reuse is inferred, not attempted

`test_no_ending_settles_before_every_required_one_is_established` asserts the
attempt cleanup remains `pending`, but it never asks the posture/lane owner to
reuse the lane or start a replacement. A pending row is not proof that every
consumer refuses reuse. Exercise the actual reuse boundary before and after
the provider ending; the first call must refuse without starting, and only the
settled retry may proceed.

## [P2] “No delivery” currently means only “not mounted”

The expired-offer case constructs an adapter after expiry, and the fixture
materializes a launch delivery at that point. The case proves no runtime and
therefore no mount, but does not prove no provider root. The daemon-free
`evidence/w32382-review-expired-delivery.py` prints the surviving launch root.

Either clarify the dossier/test name to say no runtime delivery (manager-side
materialization is allowed), or require and assert that no provider root is
materialized. Do not use one word for both states.

## Verification

- `tests.manager.test_offers`, `test_attempts`, `test_intake`,
  `test_handshake`, and `test_interrogation`: 380 tests, OK under
  `-W error::ResourceWarning`.
- Both reviewer reproductions exit 0; the expired-delivery reproduction is
  warning-clean.
- `tests.manager.test_negative_race_endings` reaches discovery but the managed
  shell is denied `/var/run/docker.sock`; Podman is absent and skips narrowly.
  No escalation was requested. The implementer's Docker run remains execution
  evidence rather than an independent rerun.

## Outcome

Changes requested. W32382 remains open for a real post-create failure, the two
missing ending seams, actual lane-reuse evidence and exact delivery wording.
