=== 7. THE WRAPPER-BOUNDARY COMPARISON, unchanged by these corrections
  CLAUDE reads a read-only credential provider and reaches an
  AUTHENTICATION decision. CODEX will not start with its state
  directory read-only — it writes beside its credential — so the
  provider must be a FILE over auth.json with the directory writable.
  Codex also refuses a HOME under /tmp outright. And BOTH need their
  state directory pre-created and owned IN THE IMAGE, because Docker
  creates a missing bind-mount parent as root.

  All of that is input to W6634, whose credential delivery mounts 0600
  files read-only at a fixed root: that shape works for a Claude-like
  runtime, does not work for a Codex-like one, and the mode has to
  admit the CONTAINER's uid — which is the same defect the reviewer
  found in the offered personal files, one layer up.
