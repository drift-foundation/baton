## [P2] `_helper_returns` is not recomputed under the AST fingerprint

`MEMOISED` contains seven cached functions: `_sources`, `_helper_returns`,
`_crossings`, `receiving_entries`, `columns_read`, `owning_validators` and
`propagated_owners`. `_helper_returns` computes `_returned_origins(_sources())`
and therefore walks the shared mutable AST.

The new `test_the_shared_trees_are_never_mutated_by_a_projection` takes its
before fingerprint, then clears and invokes only five derived projections. It
omits `_helper_returns`. Recomputing `receiving_entries` and
`owning_validators` does not close that gap because both receive the already
cached helper result.

Focused in-process evidence:

```text
clear every MEMOISED cache; warm _helper_returns once
before CacheInfo(hits=0, misses=1, currsize=1)
run test_the_shared_trees_are_never_mutated_by_a_projection
after  CacheInfo(hits=3, misses=1, currsize=1)
test result: no failures or errors
```

The unchanged miss count proves the shared-tree walker was not rerun between
the fingerprints. The normal boundedness tests warm this cache before the
invariant case, so a mutation introduced in `_helper_returns` could occur
before the baseline and then be invisible to the asserted before/after check.

Required correction: after taking the before fingerprint, clear and recompute
every derived member of `MEMOISED`—all members except `_sources`—then compare
the after fingerprint. Keep the source cache itself stable so the test still
checks mutations of the same node graph rather than reparsing a replacement.
