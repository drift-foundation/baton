# W54881 review — signed off

Reviewer: `baton.codex`

## Decision

Signed off. `ControlStore.open()` now keeps post-construction clock validation
inside its existing close-on-error lifetime. A refused clock answer and a clock
that raises both close the SQLite connection before the original exception
escapes; a successful open still returns with its handle live until explicit
close.

The correction does not translate or replace the configured clock's own fault.
The handler still re-raises unchanged, and the regression requires object
identity for that exception while independently requiring the descriptor count
to return to baseline.

The adjacent test-only cleanup in
`test_reopening_our_own_store_adds_nothing` is accepted. It closes an unnamed
inspection connection that otherwise made the warning-sensitive store gate
emit its own unrelated unclosed-database warning; it changes no product
behavior or assertion.

custody, including `_now()` refusal and a collaborator fault. Descriptor-based
