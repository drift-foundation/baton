## [P1] The focused driver still leaks a SQLite connection

The performance correction reaches all 549 probes in about two seconds and the
new fixture regressions pass, but the acceptance boundary requires temporary
stores and SQLite connections to be reclaimed per probe. Running only the
named driver with `-W error::ResourceWarning` returns `OK` and then reports an
unclosed database during finalization. `PYTHONTRACEMALLOC=10` traces it through
`test_boundary_inventory.py:5278` to `ControlStore.open()` at `store.py:261`.

The cause is not the driver's primary `BoundaryCase.store`: its cleanup is
prompt. The clock-answer probe opens a second store. `ControlStore.open()`
constructs that store and invokes `store._now()` at `store.py:284` outside its
close-on-error `try`; the refusal therefore loses the store before the probe
can register cleanup. The existing focused store test reproduces five leaked
connections while reporting `OK`.

This defect is now contained as W54881 with its own dossier at
`work/records/2026/08/finding-boundary-inventory-runtime-explosion/findings/finding-refused-store-open-clock-leak/`.
Resolve that child before claiming W54182's resource acceptance. Preserve the
prior decision that a configured clock's own exception propagates; only its
connection custody is at issue.

## [P2] The immutable-snapshot regression does not cover the cached ASTs

`_sources()` returns an immutable tuple, but every tuple member contains a
mutable `ast.Module`. The new
`test_no_caller_can_poison_a_cached_projection` checks only that the outer
container is a tuple. A bounded in-process reproduction clears the caches,
computes `_crossings()`, clears `oci.py`'s cached `tree.body`, clears only the
derived crossing cache, and loses the live `run` crossing. One caller can
therefore poison a projection another caller computes later, contrary to the
test name, implementation comment, progress claim, and recorded patch
boundary.

Either make the cached source representation genuinely non-poisonable, keep
the mutable AST cache behind an interface that is not handed to projection
callers and state/test that narrower invariant, or explicitly revise the
recorded immutability claim. The current type-only regression must not certify
an invariant it does not exercise.
