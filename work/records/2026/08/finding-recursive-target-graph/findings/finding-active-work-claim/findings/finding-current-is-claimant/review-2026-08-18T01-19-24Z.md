## Blocking findings

### R1 — a retained Current becomes impossible to query after config retirement

The confirmed decision explicitly permits a later accepted generation to
change route eligibility without rewriting the exact participant captured by
a live claim. The projection preserves that participant correctly, but
`normalize_filter()` accepts an explicit `current=TEAM.MEMBER` only while the
member is still live (`removed=0`). Consequently an authority can truthfully
project `current.participant == "lang.bee"` and refuse
`current=lang.bee` as not configured.

An additive regression now reproduces the sequence in
`tests/work/test_w245_route_and_current.py`:

1. `lang.bee` claims Work;
2. generation 2 removes `bee` from the route and participant set;
3. config acceptance preserves the live claim, as ruled;
4. `detail` still reports `lang.bee` as Current;
5. `home` with `current=lang.bee` refuses.

The explicit Current filter must be able to name the exact authoritative
claimant even when a later config marks that known participant removed. Keep
the negative refusal for identities the authority has never known, and keep
the endpoint-versus-participant refusal.

### R2 — the old endpoint-valued “Current” vocabulary still survives

The public JSON keys changed, but protocol-owned source and help still describe
the route as Current. This includes the user-facing `_handler_gate()` refusal
(`has no Current endpoint`), the `pass` help text, transition/readiness
docstrings, and several comments that future maintainers use to preserve the
authorization boundary. These must say Route for eligibility and Current only
for the exact claimant.

The documentation edits folded into this Work are also incomplete:
`docs/BATON-WORK.md` still says “The projection carries `active` (JSON)” and
still gives mutation authority to a “Current handler.” Both contradict the new
contract. Those documents are owned by W103/W104, not W245; seq 261 explicitly
kept that boundary. Do not treat their incidental edits as accepted here.
Clarify W245's PLAN/PROGRESS that W245 owns the authority/projection/CLI/TUI and
directly coupled tests/help, while the already-present public-document edits
remain unreviewed W103/W104 work after W245 closes.
