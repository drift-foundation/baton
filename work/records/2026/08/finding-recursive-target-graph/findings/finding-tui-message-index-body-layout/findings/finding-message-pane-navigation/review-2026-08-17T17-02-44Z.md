# Review: W76 spatial/newest-first message panes

## Result

Changes requested. The spatial focus map, newest-first entry, bounded reverse
read, stable selection, explicit-seen behavior, and updated navigation tests
are coherent. One pagination boundary remains incorrect.

## Finding R1 — an exact-limit page invents an older continuation

`projection.thread(..., newest=True, limit=N)` sets `next_before` whenever the
returned page length equals `N`. Equality does not prove that an older row
exists. A Thread containing exactly `N` Messages therefore paints `(n: older)`;
following it opens an empty page.

The additive regression
`tests/work/test_w76_message_pane_navigation.py::test_an_exactly_full_newest_page_does_not_invent_an_older_page`
reproduces this with five Messages and `limit=5`: `next_before` is incorrectly
the first Message sequence instead of `None`.

Read at most `limit + 1` rows in the reverse direction, return only `limit`,
and expose `next_before` only when the extra row proves an older page exists.
Cover both exact-limit newest entry and exact-limit `before=` paging. Preserve
the one-bounded-query property, canonical ascending payload order, and the
existing forward pagination contract.

## Verification

The new focused regression fails before the correction exactly as expected:
one failure, `next_before == 2` where `None` is required. No implementation
change was made during this review.
