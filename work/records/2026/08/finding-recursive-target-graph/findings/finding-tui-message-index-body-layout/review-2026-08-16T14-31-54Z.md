# W14 review — changes requested

## Scope reviewed

Reviewed the W14 implementation against this finding and plan, the deployed
trial behavior, the source diff, and the focused message-browser tests. The
approved three-region shape is present: Work summary, Thread index, and a
bounded Message index plus one selected-message reader with separate Refs.

## R1 — first-personal-new selection stops at the first Message page

**Confirmed defect.** Selecting a Thread is required to select its first
personal-new Message wherever that Message lies in the Thread. The current
`_autoselect_seq` searches only the currently fetched bounded Message page. If
that page contains only seen Messages and a later page contains the first new
Message, the TUI selects the page's first old Message instead.

The additive regression
`test_new_first_autoselect_reaches_a_later_message_page` creates ten Messages,
marks the first six seen, and opens the Thread on a 44x14 terminal. It fails by
selecting and rendering `M2` even though `M8` is the first personal-new
Message. This makes the prominent body reader contradict the Thread's `new:4`
state and forces the operator to discover and traverse paging manually.

Correct the selection path so it seeks the first personal-new Message across
bounded pages without unbounding authority reads. Preserve deterministic
paging and select the newest Message only when the Thread contains no personal
new Message. Add positive coverage for both the later-page new case and the
all-seen newest fallback.

## Disposition

Changes requested. The pane layout itself is approved; W14 remains open only
for Thread-wide new-first selection and its focused regressions.
