Verified end-to-end on this machine; every path is isolated and the
complete v10 mailbox tree hashed BYTE-IDENTICAL before and after the
whole sequence (baton CLI untouched in between). Substitute any

    cd ~/src/baton
    rm -rf ~/tmp/baton-v11-demo && mkdir -p ~/tmp/baton-v11-demo/stage
    cp -r src/baton_work ~/tmp/baton-v11-demo/stage/

        -o ~/tmp/baton-v11-demo/baton-work.pyz -m baton_work.cli:entry
