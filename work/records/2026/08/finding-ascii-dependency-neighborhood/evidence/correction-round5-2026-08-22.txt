2. [P1] THE WALK MEMO COULD HIDE A CYCLE

`state["walked"]` answers "do this branch's descendants need expanding
again", and that is a sound question. Cycle closure is a different one: it is
a property of the ANCESTRY, which the memo does not carry.

So a node first reached where its outgoing edge is ordinary, and reached
again with the other end of that edge among its ancestors, got a memo hit and
returned before `_expand_branch` compared anything with the new path. Every
edge of the two-node cycle was returned inside the requested depth and the
response called itself valid.

CORRECTED with a second boundary rather than by weakening the memo, which is
what the review asks for: `_refuse_cycles(edges)` runs after the walk, over
the edges the response ACTUALLY CONTAINS. The drawn graph either has a cycle
or it does not, and that is decidable from the edges alone — no traversal
order can hide it.

It is ITERATIVE and bounded by the occurrence cap that already bounds
`edges`, so a damaged store is reported rather than crashed on. It
distinguishes ANCESTRY from "already finished", because a node reached by two
valid paths is ordinary in a DAG and a naive visited-set check would refuse
the most common shape in this repository's own graph — a regression covers
exactly that false positive.

The refusal names the exact closing edge. Either real edge of the loop is an
exact answer, depending where the search enters it; naming a real one is the
property, because "this graph has a cycle" sends an operator through the
whole neighbourhood looking for it.

THE PATH-LOCAL CHECK STAYS. It no longer changes the ANSWER — a plain cycle
is refused either way — but it refuses at the first re-entry instead of
walking up to the whole occurrence budget round a loop.

DELIBERATELY NOT REPORTED: a cycle whose closing edge was not admitted, cut
by the cap or a branch page. The drawn graph really is acyclic, and inventing
a refusal about an edge the response does not contain would be a different
kind of lie. A regression pins both directions — invisible at depth one,
refused once the depth reaches it.
