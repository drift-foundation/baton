1. [P1] THE RENDERERS DREW EDGES THE AUTHORITY NEVER HELD

`_ordered` emitted one entry per unique NODE and every renderer paired that
node with the CENTER. For the canonical chain A --blocks--> B --blocks--> C
centered on A at depth 2 the wide form drew

  [A]
  [A] --blocks--> [B]
  [A] --blocks--> [C]        <- invented
                             <- and B --blocks--> C was dropped

That contradicts the one guarantee this view is built on. Rows now carry
their REAL endpoints — one entry per canonical edge, plus the center — and
`work` still names the far node so selection identity is unchanged. The same
chain now renders

  [A]
  [A] --blocks--> [B]
  [B] --blocks--> [C]

A new regression compares the DRAWN edge set against the projection's own
edge set, at three centers, three depths and three widths, including a shared
DAG node.


2. [P1] A STACKED ROW SELECTED A DIFFERENT WORK THAN IT SHOWED

For a downstream edge `_stacked` attached the consumer's `work` to a row that
painted the CENTER token, with the real consumer on a non-selectable
presentation row. A console would have highlighted one Work and recentered on
another.

Every selectable row now displays the selector for its own `work`. The
relationship still reads in its true direction: a downstream edge shows the
source and arrow as presentation and the selectable TARGET last; an upstream
edge shows the selectable SOURCE first. A new regression asserts the property
in every renderer, not only the one the review found.


3. [P2] THE CAP DID NOT BOUND MATERIALIZATION

`_dependency_edges` returned every direct edge as a Python list and the
caller sliced it afterwards, so an adversarial fan-out allocated memory
proportional to the whole branch while the response claimed a bounded view.
It is a `COUNT(*)` plus an ordered `LIMIT` now — the exact direct count
without the rows.

Two regressions, because the two halves are observable differently:

  - the cap is CROSSED: a branch of 240 is expanded past the page, the
    response reports `capped=true`, draws fewer than the branch, and the
    omission is exact for everything not drawn;
  - the materialization is BOUNDED: the edge helper is watched, and the rows
    it returns never exceed the page while the total it reports is the whole
    fan-out. Memory has no visible result, so asserting the outcome alone
    would have left this correction unwitnessed — and the first mutation
    proved that, passing green until the watch was added.
