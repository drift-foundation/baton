## [P2] Expanded branches still materialize beyond the occurrence cap

`_dependency_edges` correctly changed from fetch-all to `COUNT(*)` plus an
ordered `LIMIT`. `_expand_dependency`, however, passes the raw expansion value
as that limit before consulting the remaining occurrence allowance. Repeated
overflow expansion can therefore make the list as large as the direct branch
despite the 200-occurrence global cap.

With 240 direct dependents and an expanded limit of 250, the retained
regression observes `_dependency_edges` returning all 240 rows. Only the later
Python loop stops drawing at 199 far occurrences. Bound the SQL row limit by
both the requested branch page and `occurrence_cap - occurrences`, while
retaining the exact total from the count and exact omission disclosure.

## [P2] Depth-two wide rows move a node between layer columns

The approved wide form places the selected center between shortest-path
layers. `_layered` instead indents every downstream edge to the center column
and right-justifies every upstream edge to end there, regardless of depth.

For `A --blocks--> B --blocks--> C` centered on A, B is the first row's target
at column 25, then becomes the second row's source at column 0. The same node
therefore occupies two layers, and the output is an adjacency list rather than
the promised layered graph. Derive endpoint offsets from `_layers` so every
appearance of a Work stays in its shortest-path column.

## [P2] Overflow tokens are outside their branch traversal position

`_ordered` appends both center-branch tokens immediately after the center.
For an upstream center branch, this puts the center between its four visible
blockers and `[+N blockers]`. For a downstream center branch, it puts
`[+N dependents]` before all four visible dependents. This contradicts the
specified order in which overflow tokens follow their visible siblings and
would make Enter expansion jump around the eventual selectable traversal.

Place an upstream center token after its visible upstream siblings and before
the center; place a downstream center token after its visible downstream
siblings. Apply the same exact-branch rule at deeper layers.
