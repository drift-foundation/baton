## [P1] A shared DAG branch invents omissions for edges already rendered

The projection permits a node reached through two valid DAG paths, but
`_expand_dependency` re-expands the shared node's identical branch on each
path. `seen_edges` suppresses duplicate edge rows; the occurrence increment
and recursion are unconditional. The second traversal therefore consumes the
cap with edges that will not be rendered again and overwrites the branch's
complete result with a false omitted count.

With two paths to one shared node and 150 fully expanded outgoing edges, the
response returns all 150 edges yet reports `capped: true` and
`omitted[shared|downstream]: 105`. The future UI would paint an overflow token
claiming 105 hidden dependents that are already visible. That breaks the
central promise that occurrence bounds and direct omission counts describe
the rendered canonical graph exactly.

Count only rendered occurrences and make repeated valid paths preserve, not
degrade, the most complete expansion already obtained for a `(Work, side)`
branch. A correction must still allow a later shorter path to supply greater
remaining depth and must retain path-local cycle detection; a blanket global
visited-node cut would not be equivalent. Retain the shared-branch regression.

## [P2] A page/allowance tie reaches the cap without disclosing it

The new cap flag is set only when `room < page`. If four occurrence slots
remain, the ordinary branch page is four, and five direct neighbors exist,
the query admits four and omits one. The response ends at exactly 200
occurrences with `capped: false` because `room == page`.

The branch was page-truncated and allowance-truncated simultaneously; more
importantly, the view is full and no later branch can admit an occurrence.
Report the cap whenever an exact omission remains as the global allowance is
exhausted, including this equality boundary. Retain the 195-upstream plus
5-downstream regression.

## [P2] A shortcut edge moves one Work out of its shortest-path column

The column correction works for a simple chain. A legal DAG can also reach a
Work directly and through a longer path. `_walk` assigns that Work to its
shortest-path column, but the longer edge starts in a farther source column.
`_layered` clamps the gap to at least one and paints the target after that
source, so the same Work appears at columns 25 and 73.

This contradicts the correction's recorded rule that a column is a property
of the Work rather than the row. Represent the canonical shortcut without
moving its endpoint, or decline the layered form for a graph it cannot lay out
monotonically and use an honest fallback. Retain the direct-plus-three-hop
acyclic regression.
