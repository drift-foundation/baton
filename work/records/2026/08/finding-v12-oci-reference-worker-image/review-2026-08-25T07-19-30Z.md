## [P1] A latched startup fault answers another session's frame

`serve` extracts only bounded identity members, then at
`v12/worker/baton_worker.py:435` returns the pending posture fault before the
protocol and expected-session checks in `handle`. A container with a latched
bootstrap fault therefore echoes an arbitrary peer's session and exposes its
posture failure, even though the pinned common contract says every request's
session is this exact posture-specific container and wrong-session frames are
refused before agent dispatch. Startup correlation supplies an operation
identity; it does not suspend that binding.

The additive
`test_a_latched_fault_does_not_answer_another_sessions_envelope` at
`v12/python/tests/manager/test_worker_image.py:360` sends a valid bounded frame
for another session. It fails because the worker returns `code: posture`
instead of `code: session`. Validate protocol and expected session after the
one bounded identity envelope and before returning the latched fault; retain
the exactly-one-frame, non-zero-exit, and never-dispatch properties.

## [P1] The gate does not prove reproducible pinned-platform identity

The build at `tests/manager/test_worker_container.py:101` does not select a
platform, and `test_the_image_has_one_identity_and_it_is_a_digest` at line 169
only proves that one build's ID has digest syntax. It neither reproduces the
build nor compares identities. This does not satisfy the recorded requirement
to build a pinned-platform image and prove reproducible image identity.

Build the same context independently for one explicit platform, inspect the
applied OS/architecture, and compare the resulting immutable image identities.
Register both tags for cleanup before either build can create them.

## [P1] The residual-container assertion excludes every possible residue

`test_no_container_of_this_suite_survives_it` asks Docker for names containing
`baton-w6633-test`, but lines 358-359 retain only names that do **not** start
with `baton-w6633-test-`. Every container created by this suite has that
prefix, so the asserted list is empty even when a suite container survives.
The claim that the engine proves no residual containers is therefore false.
Assert over all non-empty filtered names and retain the separate allowance for
the one live image tag where needed.
