## [BLOCKER] The image implements the superseded worker I/O contract

The approved artifact-neutral boundary is now durable in
`work/records/2026/08/finding-v12-isolated-agent-workers/FINDING.md` and ordered
in that record's PLAN. The OCI worker receives read-only `/input` containing
`input.json` and declared payloads, writable `/output`, and private ephemeral
space; it publishes `/output/output.json` last. The host Worker Manager is
artifact-neutral. The umbrella PLAN explicitly requires the older
worker-control and conformance contracts to be revised before the OCI reference
worker or host manager is implemented.

The current image is incompatible with that ruling:

- `v12/worker/baton_worker.py:108-133` requires inline `task`, returns
  `workspace`, and exposes `BATON_WORKER_ASSIGNMENT`,
  `BATON_WORKER_WORKSPACE`, and `BATON_WORKER_OUTPUT`.
- `v12/worker/scripted_agent.py:52-74` executes the inline task and returns a
  recap plus the environment's workspace.
- No worker path consumes `/input/input.json` or publishes
  `/output/output.json` last.

This is not safely fixed as a local frame rename: the prerequisite contract
revision owns the exact request, output, manifest and conformance boundaries.
W6633 must remain blocked until that revision is pinned, then be revalidated
against it before implementation resumes.

The prerequisite is ledger Work `W14251`; a dependency edge now blocks W6633
on it.

## [P1] Cleanup can still erase or replace its evidence

`build_worker_image` at `v12/python/tools/worker_image.py:368-403` calls the
stage removal in `finally`, stores a completed process, and checks it only after
the protected body succeeds. If an earlier build step raises and removal
returns nonzero, the return value is discarded during unwinding, so the
documented "cleanup evidence in the log" does not exist. If the removal call
raises `TimeoutExpired` or another subprocess exception, that new exception
replaces the earlier build failure outright.

The additive daemon-free tests
`test_a_refused_cleanup_is_attached_to_the_earlier_failure` and
`test_a_cleanup_exception_cannot_replace_an_earlier_failure` reproduce those
two branches. Preserve the primary failure and attach bounded, actionable
cleanup evidence for both a nonzero result and a thrown cleanup call. With no
earlier failure, either cleanup outcome must still prevent a successful image
identity return.
