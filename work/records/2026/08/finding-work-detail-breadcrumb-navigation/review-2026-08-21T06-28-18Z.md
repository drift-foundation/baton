## Findings

### [P1] Do not append the full ancestry again on a nested re-root

`_seed_work_frames` always pushes every canonical ancestor
(`src/baton_work/tui/app.py:1295-1311`), and the `u` branch calls it without
accounting for Work frames already on `Console.nav` (lines 5157-5172).
Re-rooting `root`, then selecting its child and pressing `u`, directly
produces:

```text
after first u:   Jobs > root
after nested u:  Jobs > root > root > child
first Back:      Jobs > root > root
second Back:     Jobs > root
```

The duplicated `root` is not another containment level, and the first two Back
steps reveal visually identical scopes. This violates the universal rule that
a further drill appends one segment and every painted segment corresponds to
one revealed level.

Seed the full canonical ancestry only where the caller has no matching Work
scope (the direct-entry case). When re-rooting farther inside an already
recorded containment path, add only the missing descendant scope(s), preserving
the existing frames and their restoration state. Add a regression that performs
successive `u` operations and proves the trail is `Jobs > root > child`, then
Back reveals `root` and the original Jobs table exactly once each.

### [P1] Linked drill-through drops the far Work's real ancestry

The links Enter branch says it reconstructs the far Work's ancestry, but it
pops the links frame, pushes only the far title, and assigns `path = [far]`
(`src/baton_work/tui/app.py:5122-5136`). With a dependency pointing to a
grandchild, direct reproduction yields:

```text
actual:   Jobs > grand
required: Jobs > root > child > grand
```

Back therefore skips the parent scopes the confirmed decision requires. If
the links page was opened from an already re-rooted caller, the remaining
caller frames also prefix the unrelated far Work, producing a false mixed
ancestry.

Preserve the existing deliberate re-root semantics, but rebuild the resulting
Work frames and `path` from the far Work's canonical breadcrumb through the
shared seeding model rather than pushing one title onto whatever caller frames
remain. Add a nested-neighbor regression that checks the complete far ancestry,
one-scope-per-Back behavior, and absence of caller ancestry after a cross-tree
drill-through.
