## Changes requested

### P1 — Soft wrapping deletes spaces from serialized JSON strings

`soft_wrap()` chooses a space as its preferred break, calls `rstrip()` on the
first fragment, and then calls `lstrip(" ")` on the remainder. That behavior
is acceptable for normalized prose but not for the pinned complete JSON
payload: spaces inside a quoted JSON string are data. Repeated spaces at the
break disappear, as does each later break space.

The additive regression
`test_wrapping_preserves_spaces_inside_a_json_string` in
`tests/work/test_w48_event_payload_json.py` removes only the structural
continuation prefix and requires the original logical JSON line byte-for-byte.
On the reviewed tree it fails because
`"alpha   beta gamma delta"` becomes `"alphabeta gammadelta"`.

Preserve every source character while inserting only the continuation prefix.
The wrapper may hard-break when necessary, but it must not trim serialized
content. Retain the current progress guarantee for pathological widths and the
logical-line indentation rule.
