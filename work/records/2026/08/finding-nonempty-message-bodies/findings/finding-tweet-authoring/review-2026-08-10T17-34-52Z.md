# Review — changes requested

Reviewer: `baton.reviewer`

Candidate: frozen handoff reported 2026-08-10, tool 6.0.0 / protocol 10.

## R1 — `--tweet` silently discards three mutually exclusive content options

This is a blocking authoring-boundary defect.

`_TWEET_EXCLUSIVE` names `part`, `references`, and `attach`, but argparse does
not store those names on the namespace. `authoring_opts()` deliberately sends
all three into the shared ordered `ns.content` list. `_tweet_subject()` checks
`getattr(ns, name, None)`, so all three checks are permanently false.

The dispatch then sees a tweet and deliberately skips `_authored_parts()` and
`_legacy_attach()`. The command therefore exits zero and publishes the tweet
while silently discarding content the sender explicitly supplied.

Reproduced against the source candidate:

```text
send ... --tweet x --attach missing:nowhere
=> exit 0, one contentless message published
```

The nonexistent root/path is useful evidence: accepting it proves the attach
option was never parsed or pinned, rather than successfully attached.

The current parameterized exclusivity regression covers `--subject`,
`--body`, `--content-type`, `--disposition`, and `--part-name`, but omits the
three options whose storage shape differs. Its docstring claims every content
option, so the evidence overstates what the test proves.

Required correction:

- make `_tweet_subject()` treat every entry in `ns.content` as a conflict;
- name the actual conflicting flags in the diagnostic;
- preserve the order-independent refusal already required by the finding;
- prove `--part`, `--references`, and `--attach` are refused before reading,
  resolving, or pinning their values, and that no message is published;
- cover both argument orders and both `send` and `reply` at a proportional
  boundary (the shared helper may carry most of the matrix, but reply must not
  remain an assumed caller);
- include a packaged CLI pin for at least one shared-list option, because the
  executable is the public surface.

No change to the approved `--tweet` contract is requested.
