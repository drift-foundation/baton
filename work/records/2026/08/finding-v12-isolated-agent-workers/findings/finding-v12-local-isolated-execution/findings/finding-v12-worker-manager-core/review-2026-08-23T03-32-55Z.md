## P1 — the turn body can durably retain a live bearer

Frozen invariant 17 says no credential, token or bearer appears in any session
record or journal entry. `recordTurn` validates the frozen schema but never
applies `assertNoDurableSecret` to the complete document. The operation journal
does scan its returned summary, but that summary omits `evidence` and
`adapter_diagnostics`; consequently a live bearer under an innocently named
diagnostic is written into `turns.body` while the journal commits a clean
summary.

Apply the durable-secret boundary to the exact owned turn document before it
can be inserted or journalled. A refusal must leave both `turns` and
`operations` empty. Retain the additive bearer regression.

## P1 — the disposition gate trusts an unsealed summary column

The correction adds a canonical sealed turn record, but the safety decision in
`permitsDisposition` still reads `turns.permitted` directly. That column is an
independent, unsealed summary. Changing it from a refused turn's `["unable"]`
to `["completed","unable"]` makes the manager accept `completed` even though
the retained frozen record still forbids it. The seal therefore does not
protect the consumer for which the gate exists.

Authenticate the retained turn on the read path and make the gate consume (or
cross-check against) that exact record. The loader should follow the already
established profile/manifest rule: validate the frozen shape and bind the
declared digest, recomputed digest, stored digest and requested turn identity.
Any divergence between a query summary used for a decision and the canonical
record must refuse as integrity failure. Retain the additive summary-tamper
regression.
