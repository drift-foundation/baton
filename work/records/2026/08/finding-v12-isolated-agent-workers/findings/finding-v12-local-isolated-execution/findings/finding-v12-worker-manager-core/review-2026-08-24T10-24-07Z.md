## Finding

### P1 — callers can supply a negative traversal depth and bypass the bound

`contracts.canonical.canonical_text(value, _depth=0)` and
`contracts.pod.own(value, *, _depth=0)` are both exported public functions.
Their `_depth` parameters are not private merely because their names begin with
an underscore: Python callers may pass them directly. Supplying a sufficiently
negative value lets a document deeper than `MAX_DEPTH` canonicalize and become
owned successfully.

This is the same rule/site defect the correction intended to close, one level
lower: the bound is now shared, but its enforcement state is caller-controlled.
Give each public operation a signature containing only its genuine operands and
move recursive descent into a private helper, or otherwise refuse supplied
traversal state before it can affect the decision.

Regressions:

- `tests.manager.test_canonical.WhatCannotAcquireADigest.test_a_caller_cannot_choose_the_canonicalizers_traversal_depth`
- `tests.manager.test_pod.ABehaviourBearingContainerNeverEnters.test_a_caller_cannot_choose_the_ownership_traversal_depth`
