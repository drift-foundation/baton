## P1 — retained reads do not bind the full requested session identity

Frozen §3.1 makes the provider-session id part of the full session reference,
and §6.4 rejects an event whose reference is not the consumer's session.
`eventRecordOf(store, sessionRef, sourceSeq)` accepts that full reference, but
uses only attempt, posture and epoch to select the row. Its
`authenticateRetained` helper then checks the seal and source sequence only;
it never compares the retained `agent_session_ref` with the reference the
caller asked for.

Consequently, a caller asking for provider session B receives a retained
event sealed for provider session A when the other three components agree.
That is the same identity mismatch the write path correctly refuses, exposed
through the read path.

After authenticating the retained document, bind its complete normalized
session reference to the requested one, including `provider_session_id`, and
refuse a disagreement as `runtime-observation.identity-mismatch`. Preserve
null for a genuinely absent `(attempt, posture, epoch, source_seq)` row and
fresh ownership on every successful read.

## P2 — sealing non-durable input leaks an open interpreter error

`sealEvent` calls `structuredClone` directly on content, tool-call data and
adapter diagnostics before the event reaches its schema/canonical boundary.
A non-cloneable member therefore escapes as raw `DataCloneError`. The frozen
outer taxonomy is closed, and malformed/unnormalizable event content belongs
to `integrity.schema`; a provider-facing caller cannot map an interpreter
exception onto that wire contract without re-deriving policy.

Prove and own the durable value before constructing the frame, or translate
clone/canonical representation failures into `ContractError` with the closed
`integrity.schema` pair. Preserve an existing `ContractError` unchanged so a
more precise canonical failure is not flattened.
