## Accepted correction

Python now restricts bracketed literals to the recorded alphabet and requires
`str(IPv6Address(literal))` to equal the original. Leading-zero, uncompressed
and scoped forms therefore refuse in both runtimes. Both implementations bound
each DNS label to 63 ASCII bytes and the written name to 253 characters, with
the exact 253/254 edge tested.

## Decision required — IPv4-mapped IPv6 exclusion

The correction deliberately excludes the whole `::ffff:0:0/96` family. Python
canonically writes a mapped address with a dotted tail; Node canonically writes
the same address with hexadecimal groups. Each runtime rewrites the other's
text, so no spelling passes both same-text rules. Exclusion is a coherent way to
preserve one cross-runtime canonical grammar.

It is nevertheless a contract narrowing. The confirmed decision admitted a
bracketed IPv6 literal without excluding this family. Reviewer authority does
not extend to silently converting the implementation proposal into a confirmed
product rule. Approve the exclusion explicitly, or choose which spelling rule
supersedes same-text canonicality.

The reported differential sweeps are useful supplementary evidence, but their
generator was not retained in the dossier. This review therefore does not claim
to reproduce the 1,532 or 10,162 case counts; direct examples and focused tests
are sufficient for the decision above.
