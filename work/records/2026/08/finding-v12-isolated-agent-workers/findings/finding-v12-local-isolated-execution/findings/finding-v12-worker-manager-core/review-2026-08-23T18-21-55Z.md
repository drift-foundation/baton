## Findings

### P1 — the post-commit answer re-reads an untrusted session reference

`handleTransportLoss` passes the caller-owned `sessionRef` to
`observeAgentSessionState`, which proves and binds it and commits the move to
`unknown`. The function then spreads and reads that same caller object again
to construct `agentSessionRef`. A getter-backed reference can identify
provider session A for the durable observation and provider session B for the
answer. The spread also copies arbitrary extra members despite the frozen
reference's closed shape. The reproduced call commits A's axis to `unknown`
and returns B plus `untrustedExtra`.

Snapshot and validate the four reference members once before the mutation,
pass only that owned reference to the axis, and return that same owned value.
Nothing caller-owned may be read after the durable observation commits.

### P1 — the options envelope is not validated before the mutation

Parameter destructuring handles only an object-shaped options value. `null`
escapes as a raw `TypeError`; booleans, strings, and arrays are silently
coerced to an object with a missing member, default `turnInFlight` to false,
and commit the axis to `unknown`. This contradicts the slice's own rule that
the outcome-deciding fact is stated and malformed values close as
`integrity.schema` before any move.

Prove the options envelope before calling the axis. Preserve the deliberate
omitted-options default if desired, but every supplied non-record container
must refuse as `integrity.schema` and leave the session state unchanged.
