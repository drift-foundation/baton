Additive regressions
--------------------
File: v12/python/tests/manager/test_attempts.py

1. ActivationNeedsAllThreeToAgree.
   test_an_exact_reactivation_replays_one_byte_stable_answer

   The first activation returns already_fixed=False and records that document
   in the operation journal. An identical later call takes the fixed-row
   shortcut before store.transact and returns already_fixed=True. The same
   operation therefore has two answers depending on arrival timing. A racing
   second manager that read before the first commit replays False from the
   journal, while the same call beginning after commit synthesizes True.

2. ObservationsMoveAlongTheirOwnAxis.
   test_unhashable_axis_and_value_are_contract_refusals

   A list axis raises raw TypeError at `axis not in TRANSITIONS`; a list value
   raises the same at `value not in moves`. Both happen before the closed-set
   refusal the inventory claims owns these caller entries.

3. WhatOnlyAnotherWriterCanCause.
   test_a_stale_observer_translates_only_database_contention

   A clock hook pauses one manager after its deferred savepoint has read the
   old axis and immediately before its conditional UPDATE. A second manager
   commits the transition. The stale writer then raises raw
   sqlite3.OperationalError('database is locked'). The frozen host classifies
   only SQLite busy/locked result codes as runtime-observation.state-regression
   and deliberately leaves trigger/constraint/storage failures unclassified;
   the Python port omitted that contention-only translation entirely.
