Python observations
-------------------
The empty-port forms are refused because an empty string is not decimal.
The out-of-range ports are accepted because every character is decimal and no
range is checked. The malformed bracket and percent forms are accepted because
every character belongs to the broad _AUTHORITY alphabet; no host parse follows.

The artifact out-of-range case is a regression in an ordinary authority:
urlsplit.port would raise ValueError, but the new shared helper never reads it.
