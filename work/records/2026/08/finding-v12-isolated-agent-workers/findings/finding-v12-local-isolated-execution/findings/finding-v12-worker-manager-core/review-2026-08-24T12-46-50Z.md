# Independent review — closed shapes, adopted rows and outbound constructors — 2026-08-24

## Outcome

Changes requested under PLAN 4bx/4bz; Cut D remains unstarted. The three PLAN
4cc witnesses are corrected centrally and the SQL-row/outbound-constructor work
is accepted as far as delivered. The new inventory still omits capability
values, capability operands, variadic public parameters and semantic members of
injected documents. Those omissions admit wrong durable identities and leak raw
TypeError/sqlite3.IntegrityError. Refusal replay also adopts one persisted value
twice.

## Accepted

Exact inbound member sets, per-variant member sets, independently discovered
SELECT crossings, per-table adopted row contracts and the outbound constructor
routing are present. The previous extra-projection, incomplete-commit and
malformed-adopted-deadline regressions pass. All 455 delivered methods pass at
source with one ambient-version skip.

## P1 — the receiving universe still excludes input forms

`receiving_entries()` enumerates ordinary positional/keyword-only parameters,
capability calls and SELECT statements. It does not enumerate `*args`/`**kwargs`,
injected attribute values or the caller-supplied capability objects that
`NOT_INPUTS` removes.

The gaps are concrete:

* AuthorityPort accepts an unencodable bound participant because the inventory
  sees session method calls but not `session.participant`.
* `mint_bearer` is excluded as a caller input, yet nothing types it at
  construction or operation entry. A non-callable value performs authority
  reads and expiry processing before escaping as raw TypeError.
* Nine public outbound constructors take `**members`; all are absent from the
  claimed every-public-parameter universe, while the ordinary-parameter
  `offer_bearer` alone appears.

Derive every signature form and every injected value source, not only calls.
Capability operands and capability answers are different entries: construction
types the former, the receiving port owns the latter. Exceptions must point to
the actual constructor owner, not assume one exists.

## P1 — closed member sets do not own member contracts

`boundaries.document` now proves exact POD and the exact member set, but the port
does not establish the semantic contracts of members it persists or branches
on. A projection with integer `authority_uuid` is accepted and issued. A claim
answer naming another participant is accepted and durably recorded; a text
`generation` reaches SQLite's INTEGER column and escapes as raw
sqlite3.IntegrityError after the claim answer exists.

The same lexical entry/owner/probe model must extend to the semantic members of
injected documents: durable identities/text, generation domain, nested Work
reference and relationships to the bound participant/requested Work. Exact POD
is the safe representation; it is not the field contract.

## P1 — refusal replay adopts the same persisted value twice

`_operation_row` owns the operation row and proves that `refusal` decodes. The
replay path then calls the public `revive_refusal`, which calls
`boundaries.adopted` and `boundaries.document` again. A focused patch probe makes
that second adoption fail and shows exact replay reaches it.

Keep the exported caller boundary for direct `revive_refusal` use, but give the
already-owned internal replay path a trusted decoder/constructor. This is the
deletion half of PLAN 4bz, not an additional defensive check.
