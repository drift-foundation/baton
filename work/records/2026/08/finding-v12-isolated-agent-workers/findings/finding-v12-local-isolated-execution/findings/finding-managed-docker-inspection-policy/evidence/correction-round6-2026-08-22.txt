5. STATED LIMITATION, NARROWED AND RE-MEASURED

A blank line consisting of a lone CARRIAGE RETURN loads in the evaluator and
is still refused here. That is the existing CRLF limitation this module has
carried since round 3, not a new one: a lone CR on a line is a whole-file line
-ending property, and this generator emits LF. A TAB is different in kind —
it arrives from an operator pressing Tab on an empty line while hand-editing
the ruled file, which is exactly the case the accepted-spelling boundary
exists for.

Recorded so the next reader knows the narrowing is deliberate and measured
rather than an oversight of the same class.
