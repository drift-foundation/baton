## [P1] The first committed result is not the durable result

`ControlStore.transact` records `_durable(result)` but returns `result`
itself. A custom `toJSON` therefore makes the first answer the caller-owned
source object while an exact retry returns the parsed journal representation.
The dossier pins both a byte-stable operation result and “durable rows and
returned values are copies, never caller-owned aliases”; this path satisfies
neither. It can give the first caller `{transient: true, toJSON() {...}}` and
the retry `{accepted: true, assignment_id: ...}` under the same operation
identity even though the action ran once.

The parsed value already produced from the one serialization is the committed
answer. Return that canonical copy on the first call as well as recording its
exact bytes; do not serialize or invoke caller behavior a second time. Retain
the additive regression, which requires the first answer, exact retry and
journal representation to agree and requires the first answer not to alias
the action's object.

## [P1] Thenable classification consumes a different continuation than settle

`withSecret` reads `outcome.then` to decide whether ownership transfers, then
passes `outcome` to `Promise.resolve`, which reads `then` again. Promise
assimilation can read it further while propagating the same value. A stateful
thenable that exposes its continuation on the first read and `undefined` on
the second is classified as asynchronous, but the continuation is never used:
the wrapper settles and releases the bearer while the represented act's gate
is still pending. The regression observes four reads and the premature
release.

Capture the thenable continuation once and assimilate that captured callable
with its original receiver, releasing only when that continuation settles.
Getter failure must retain the existing synchronous cleanup. The scoped API
does not need to be removed: reference counting and ordinary Promise behavior
are sound now, and one-read thenable adoption closes its remaining advertised
boundary. Retain the additive stateful-thenable regression.
