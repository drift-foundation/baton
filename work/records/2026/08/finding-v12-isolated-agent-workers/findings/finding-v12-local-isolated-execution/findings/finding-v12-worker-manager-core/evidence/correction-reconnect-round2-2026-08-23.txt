2. THE FINDING, AND THAT MY OWN CORRECTION CARRIED IT

The previous round's finding was "a default is for an argument nobody gave,
not an argument somebody gave wrongly". I wrote that sentence into the code —
and then implemented it as

    typeof options !== "object" || Array.isArray(options)

which is true of a Date, a Map, a regular expression and every class instance.
Each of those took the absent-member default and COMMITTED the epoch from
`prompting` to `unknown`. The defect the paragraph describes survived the fix
aimed at it, because "not a primitive and not an array" is not "is a record".

That is the third time in this Work that a check written as an ALLOW rule was
implemented as a DENY rule — the handshake slice's two method surfaces were
the first two, and the correction there says a deny list "silently widens when
an SDK adds a method". A type test that admits everything except two known
shapes widens the same way, on the day a caller passes a shape nobody listed.

`in` had the matching problem one line down: it walks the prototype chain, so
a member the caller never put in the document it passed would have been read
from something else.


3. THE CHANGE

A RECORD IS A PROTOTYPE TEST. `isPlainRecord` admits an object whose prototype
is `Object.prototype` or null and nothing else. That is the only test that
GENERALIZES: enumerating the exotic types this contract happens to know would
admit the next one on the day it appeared.

`Object.create(null)` is admitted deliberately — it carries no class and no
behaviour, so it is a document. A case drives it, and drives a promise, a
typed array and a boxed string as shapes this contract has never listed and
refuses anyway.

The optional member is read with `Object.prototype.hasOwnProperty.call`, so
what was GIVEN is what is on the object.

Refusal messages name the value by its constructor rather than serializing it:
a Map and a class instance both stringify to `{}`, and a refusal reading "{}
is not an options document" would tell a caller it had passed an empty
document.
