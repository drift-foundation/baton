## Findings

### P1 — naming a rejected type executes its hostile metaclass

`contracts.errors.name_value` and `type_name_of` read `kind.__name__` through
ordinary attribute dispatch. In Python, the class object is an instance of its
metaclass, so a caller-controlled metaclass can run or raise from
`__getattribute__`. `own(Value())` consequently escapes as the caller's
`AssertionError` instead of the closed `ContractRefusal`, after recording that
the metaclass ran. This contradicts the cut's central rule that a refusal never
runs the value it refuses. Read the type-owned name without metaclass dispatch,
then retain the existing encoding and output bounds.

Regression:
`tests.manager.test_pod.ABehaviourBearingContainerNeverEnters.test_naming_a_rejected_type_does_not_run_its_metaclass`.

### P1 — the exported closed category/code pairing is caller-mutable

`ERROR_CODES` is a public mutable dict and `ContractRefusal` consults that same
object at every raising site. A caller can append `caller-invented` to the
`policy` tuple and immediately construct a supposedly closed
`policy/caller-invented` refusal. The frozen Node oracle protects both the
outer record and its member lists; the Python surface must likewise keep the
authoritative pairing immutable or validate against a private immutable value.

Regression:
`tests.manager.test_frozen.ThePairIsCheckedWhereItIsRaised.test_a_caller_cannot_open_the_frozen_pairing`.

### P2 — escaping happens after the diagnostic bound and expands past it

`name_value` truncates an exact string to 60 code points and then calls
`ascii()`. Four rejected astral member names therefore produce a 1,933-character
message despite the standing under-500 property. `label_of` has the same order:
160 lone surrogates become a 1,004-character message. The operation is bounded,
but the retained caller-controlled rendering is not bounded in the unit the
message promises. Bound the rendered, encodable form as well as the work used
to produce it.

Regression:
`tests.manager.test_pod.AnExactRecordCarriesExactlyItsMembers.test_escaped_unicode_does_not_expand_a_bounded_diagnostic`.
