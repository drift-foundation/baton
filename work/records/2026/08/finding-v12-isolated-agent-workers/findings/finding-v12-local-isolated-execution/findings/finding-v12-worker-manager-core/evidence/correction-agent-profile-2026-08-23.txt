2. THE TWO

[P1] THE GENERIC WRITER BYPASSED THE ONE CERTIFICATION ROUTE. `certifyProfile`
took `kind` as an operand, accepted `agent-session`, and wrote a
caller-authored digest straight into the same table. So the shape, seal,
posture-policy and secret checks I had just built were avoidable by not
calling the entry point that performs them, and `isAgentSessionProfileCertified`
then reported that digest certified.

A composing entry point that a caller may decline to call is a suggestion.

[P1] AN AGENT-SESSION PROFILE CERTIFIED THE RUNTIME AXIS. `certifiedProfile`
asked only for the digest and `withdrawn_at`, so a genuinely certified
AGENT-SESSION profile satisfied `issueOffer`'s RUNTIME check. The two are
separate contract axes with separate schemas, seals and policies. A digest
certified under one is not certification under the other EVEN WHEN THE BYTES
ARE GENUINE — and "certified" without a kind is a question that does not have
one answer.

Both consumers name their kind now and fail closed on a cross-kind row.

[P2] The schema byte-identity regression the review added is retained.


3. ONE PLACE I DID NOT DO WHAT THE CASE IMPLIED, AND WHY

The review's forge case calls the generic writer and then asserts the lookup
reports false — which reads as "drop the operand silently". I refused the
operand instead, and kept the review's assertion underneath a `throws`.

THE REASON IS A HAZARD IN THE OTHER READING. Silently dropping a supplied
`agent-session` would satisfy the case while writing the caller-authored
digest as a certified RUNTIME profile — turning an attempted agent-session
forgery into a SUCCESSFUL one on the axis the caller never named. The case
would pass and the store would be worse.

So the writer takes no `kind` at all and says so when one is supplied, which
is the rule the authority's sessions already apply to `participant`: an
operand that looks authoritative and is not is worse than no operand. A case
of mine also asserts that a refused kind certifies NOTHING, on either axis.

If the reviewer reads the acceptance differently I would rather be overruled
than have quietly reinterpreted their case.
