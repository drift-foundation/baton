2. WHAT CHANGED, BY FINDING

  [P1] The frozen schema runs BEFORE any semantic helper, and the reply
       exemption is reachable only from a schema-proven document —
       `verifyOperationSignature` refuses without that proof, so a caller
       cannot reach it by skipping the schema. `ajv` 8.20.0 is pinned exactly
       and resolved from the committed lockfile.

  [P1] Negotiation takes the manager's own extension support, limits and
       certified profile; selects the exact extension INTERSECTION; returns
       the complete frozen `control.welcome` body, validated as one before it
       is handed back. Limits intersect at the MINIMUM — the pair both sides
       survive.

  [P1] Observations are keyed (attempt, incarnation, source_seq), so an
       adapter restart beginning again at sequence 1 is admitted rather than
       colliding, and manager_seq is separately unique per attempt.

  [P1] The operation journal stores the whole sealed refusal — closed
       category and code, retry and operation-state facts — so a durable
       policy.retention replays as itself. settled_at records an injected
       manager clock.

  [P2] The store INSPECTS before it mutates: an existing store is validated,
       a fresh one is initialized inside one transaction, the busy policy is
       in force before any lock is taken, and every constructor failure
       closes the handle.

  [P1] Canonicalization is closed over the admitted value space: negative
       integers, negative zero, lone surrogates, sparse arrays and non-plain
       objects are refused rather than digested.


3. WHY THE CANONICALIZER STAYS LOCAL WHILE THE VALIDATOR DOES NOT

RFC 8785's hard part is number formatting, and this contract has no numbers
to format: section 3.2 forbids floating point, NaN, infinity and negative
zero, so the admitted space is non-negative safe integers, which have one
spelling. What remains is member ordering by UTF-16 code unit and string
escaping, both of which JavaScript already does correctly once lone
surrogates are refused. JSON Schema, by contrast, has a large construct
surface I would be re-deriving — and this repository has caught me three
times implementing a specification from my reading of it.

placement.test.mjs's "the prototype imports nothing from the v11 product
