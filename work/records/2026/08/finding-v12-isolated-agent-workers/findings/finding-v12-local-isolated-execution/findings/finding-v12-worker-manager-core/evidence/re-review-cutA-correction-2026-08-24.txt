RESIDUAL BYPASS

Both public recursive operations expose their internal traversal counter:

  canonical_text(value, _depth=0)
  own(value, *, what="operand", _depth=0)

A caller can start the counter below zero. An independently run probe built a
document MAX_DEPTH + 20 levels deep and produced:

  len(canonical_text(deep, _depth=-100))  -> 58
  type(own(deep, _depth=-100)).__name__   -> list

The same document is refused on both default paths. A leading underscore does
not stop a caller from supplying a Python argument, so the traversal state is
an effective operand even though the public contract does not name it.

RECOMMENDED PATCH BOUNDARY

Keep recursive bookkeeping out of both public signatures. A public wrapper
accepts only the document (and `what` for ownership), initializes depth itself,
and calls a private recursive helper. The helper carries depth internally.
This closes the bypass without duplicating the bounds or changing accepted
documents.
