2. [P1] CONCURRENT EXACT ISSUE STILL RETURNED A MISMATCHED SECRET

I moved the replay check before minting and left the DECIDING replay inside
`transact`, after it. Two concurrent exact issuers both pass the optimistic
check; the winner commits, `transact` hands the loser the winner's committed
record, and the loser returned it beside its own freshly minted bearer.

That is the original unusable pair, under exactly the concurrency the
operation journal exists to settle — and it is the second time I have fixed
the sequential shape of a race and left the concurrent one. The pre-check is
still worth having (it refuses without minting in the common case), but it is
not the decision.

CORRECTED: the record `transact` returns is compared with the verifier this
call's bearer derives. If it does not match, this call lost, and the answer is
a refusal with no secret in it.


3. [P1] TTL DID NOT RELEASE AN OFFER NOBODY ANSWERED

`expireOffer` was reachable only from the LATE-DECISION branch of
`acceptOffer`. An offer whose worker never answered stayed `issued` with an
unspent verifier and held the per-Work unique index forever — so a bound that
depends on the holder of an expired authorization sending one more message,
which is not a bound.

CORRECTED: `expireOverdue` is manager-owned time processing that needs no
message from anybody. It runs at reissue, scoped to that Work, and at restart
recovery, unscoped — so recovery reports what is really live rather than
counting rows the clock has already ended. An elapsed offer settles VISIBLY as
`expired` with its verifier consumed, so an audit can tell it from a decline
and from an offer that never existed.


4. [P1] THE ISSUE SIGNATURE OMITTED ITS AUTHORITY BINDING

It carried `workId` while the row persists `authority_uuid` too, so reusing an
issue identity against ANOTHER authority read as an exact replay rather than
an operation collision. A changed durable operand is not an exact replay, and
the authority a Work belongs to is as durable as the Work.

CORRECTED: the full authority-scoped binding rides the signature.
