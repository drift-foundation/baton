`Array.isArray` throws on a revoked Proxy. The envelope path first translates

unchanged, but the promised closed refusal does not survive.

part of the translated boundary, including array classification for both the
envelope and member diagnostic paths. A catch used to establish a closed

use stable manager-owned text. Retain the two additive regressions in
`v12/test/worker_manager_agent_reconnect.test.mjs` and preserve all earlier
