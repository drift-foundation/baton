## Remaining finding

### P1 — “object” is still accepted as “options document”

The envelope guard rejects primitives and arrays but accepts every other
JavaScript object. Dates, Maps, regular expressions, class instances, and an
object whose `turnInFlight` is inherited are therefore treated as valid
options. Each reproduced call takes the absent-member default and commits the
session from `prompting` to `unknown` instead of refusing before mutation.

This is the same rule the correction states: a default is for an argument
nobody gave, not an argument somebody gave wrongly. An options document must
be a plain record—`Object.prototype` or null prototype—and the optional member
must be tested as an own member rather than with prototype-walking `in`.
Non-record objects must close as `integrity.schema` and leave the axis
unchanged.
