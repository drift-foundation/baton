MALFORMED ABSOLUTE URI PROBE

  validateUri("https://[") accepted.

The frozen schema accepts the string because AJV URI format assertions are
deliberately disabled. contracts.mjs validateUri recognizes a scheme, then
catches and ignores new URL(uri)'s parse failure as though every parse failure
proved an opaque no-authority URI. The copied, schema-first manifest trust
entry therefore accepts and seals the malformed source locator.

BYTEWISE CONTENT ORDER PROBE

  paths = ["\u{10000}.txt", "\uE000.txt"]
  paths[0] < paths[1]                    => true
  Buffer.compare(utf8(paths[0]),
                 utf8(paths[1]))         => 1

The current strict `<` comparison is UTF-16 code-unit order, not the frozen
contract's bytewise UTF-8 order. The validator accepts the counterexample,
resealed with matching aggregates and tree digest, although its entries are
backwards under the required order.

assertNoDurableSecret recursively examines object member NAMES only. It never
compares string values with the ephemeral bearer supplied to the manager, so
the store's two new calls do not enforce the §13 value property. The earlier
claim_token-key regression remains useful but proves only one serialized
shape. The two new store tests also assert that no operation row may survive a
secret-leak refusal.

    manifest, event, artifact reference or operation result, and logs,
    errors and diagnostics redact it.

The Python design model parses URIs with urlsplit and orders paths with
Python's Unicode scalar ordering. For valid Unicode scalar strings that order
agrees with UTF-8 byte order at the BMP/astral boundary; JavaScript UTF-16
ordering does not.
