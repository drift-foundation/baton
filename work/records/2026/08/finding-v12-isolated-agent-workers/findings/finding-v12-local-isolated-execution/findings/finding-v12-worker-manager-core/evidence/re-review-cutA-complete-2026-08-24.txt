ADDITIVE REGRESSIONS

1. tests.manager.test_pod.ABehaviourBearingContainerNeverEnters.
   test_naming_a_type_does_not_run_a_metaclass_descriptor

   A metaclass property installed as __name__ records that it ran.
   own(Value) raises ContractRefusal, but the property ran once. Directly
   calling type.__getattribute__ skips an override; it does not bypass the
   metaclass descriptor protocol.

2. tests.manager.test_frozen.ThePairIsCheckedWhereItIsRaised.
   test_the_authoritative_pairing_is_actually_frozen

   Replacing errors._PAIRING["policy"] with a frozenset containing an invented
   code causes ContractRefusal("policy", "caller-invented", ...) to succeed.
   The member values are immutable; the authoritative outer dict is not.

3. tests.manager.test_validate.TheLibraryDecidesTheContract.
   test_a_caller_supplied_validator_is_not_executed

   Passing a hostile object to exported validate_against executes its
   iter_errors method and lets the caller's AssertionError escape.

4. tests.manager.test_validate.TheLibraryDecidesTheContract.
   test_mutating_the_readable_schema_does_not_change_validation

   Temporarily replacing WORKER_CONTROL["oneOf"] with [] changes the fixed
   worker-control validator's answer. _WORKER_CONTROL.schema is the exact
   exported WORKER_CONTROL object, so the readable copy is live authority.

5. tests.manager.test_canonical.WhatCannotAcquireADigest.
   test_canonicalization_enforces_the_owned_shape_bounds

   A document beyond MAX_DEPTH, a list beyond MAX_MEMBERS and a dict beyond
   MAX_MEMBERS all canonicalize successfully even though own refuses them.
   All three subtests fail.
