## Remaining finding

### P2 — reflection is guarded only after the unguarded decision

The correction says the prototype comparison is wrapped to translate host or
Proxy reflection failure, but `isPlainRecord` first calls
`Object.getPrototypeOf(options)` without that wrapper. A Proxy whose
`getPrototypeOf` trap throws therefore leaks its arbitrary `Error` before the
wrapped comparison in `describe` can run.

The same "document, not behavior" rule is incomplete at the optional member.
After accepting a plain record, the boundary checks ownership and then reads
`options.turnInFlight`; an own accessor is executed and its arbitrary
exception escapes. An accessor is behavior, not a boolean field in a document.

Take the prototype snapshot exactly once inside a translated boundary and use
that same result for the plain-record decision and coarse description. Inspect
the optional member through one guarded own-property descriptor; accept only
an absent member or a data descriptor, and validate the descriptor's value
without invoking an accessor. Translate descriptor/reflection failures to
`integrity.schema`. Retain both additive regressions:

- `W2929 fourth review: prototype reflection failure uses the closed pair`
- `W2929 fourth review: an options member is data, not behaviour`
