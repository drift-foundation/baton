3. THE CORRECTION IS A MASK, NOT A PARSER

Comment spans are blanked to spaces before any structural scan, so
`matchingParen`, the whitespace accounting and the operand reader never see
comment text at all. That is what satisfies the review's constraint directly:
a body carrying quotes, commas, brackets or parentheses cannot become syntax
because it never reaches the splitter. Length is preserved, so every offset —
and therefore every quoted refusal fragment — still lines up with the
original text.

Two boundaries are deliberately NOT crossed by the mask:

  - a `#` inside a STRING is data. The walk tracks quote state with the same
    escape rule the rest of the module uses, so `pattern=["not#docker"]` is
    untouched and reads back as ONE operand.
  - a TAB before the `#` is a tab in CODE and stays refused, because the
    evaluator refuses it. Only the comment BODY is blanked.
