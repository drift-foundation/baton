# Independent corrected-foundation re-review — 2026-08-22T17:30:46Z

**Verdict:** changes requested. The six findings from
`review-2026-08-22T16-37-37Z.md` are corrected: AJV now closes the schema
before semantic dispatch, negotiation forms a valid welcome from both sides'
support, observation identity includes incarnation, durable refusals replay
their complete outcome and manager timestamp, incompatible stores are
inspected without mutation or handle leakage, and the previously reported
canonical value negatives refuse. Five further foundation boundaries remain
before orchestration may build on this slice.

## [P1] “Schema-proven” is still a caller-supplied boolean

`verifyOperationSignature` is exported and accepts `{ schemaProven: true }`
as sufficient proof. Nothing binds that boolean to AJV having validated this
specific document. The regression calls the public helper with a misspelled
`message_type: "commmand"`, a changed durable reason and the stale operation
signature; self-attesting the boolean reaches the non-command exemption and
accepts the frame.

That is the first review's exact W4487 trust bypass through a lower-level
entry point. Do not expose a forgeable proof bit. Keep signature verification
inside the schema-validating trust entry, make the helper private, or pass a
validated/branded document which only the validator can produce. The reply
exemption must be unreachable for every document that has not itself passed
the frozen schema.

## [P1] The trust entry returns the caller's mutable object

`validateAgainstSchema` and `validateEnvelope` return their input object.
After all schema, digest, signature and semantic checks succeed, the caller
can mutate the same body's durable operands and the value downstream code
regards as validated changes with it. This contradicts the dossier's explicit
boundary that every durable 1.0 object is copied and sealed, and turns the
validation result into a time-of-check/time-of-use alias.

Clone before validation and return the independently owned validated value;
the digest/signature/semantic checks and the returned object must all refer
to that one copy. Add mutation-after-validation coverage at nested members.
Freezing the returned value is an internal choice; ownership isolation is not.

## [P1] A committed `null` result executes again on exact retry

`ControlStore.replay` uses `null` both for “no operation row” and for the
valid JSON result `null`. `transact` therefore treats an exact replay of a
committed null-returning operation as new, runs the action again, and only
then fails on the existing journal primary key. The reproduced action count
has already advanced twice when the `UNIQUE constraint failed` exception is
raised.

This violates effectively-once at the journal foundation. Represent row
presence separately from the returned value, for example as an explicit
`{ found, value }` decision or a private sentinel. A committed JSON `null`
must replay `null` without entering the action.

## [P1] Canonicalization accepts invalid Unicode in member names

The correction checks lone UTF-16 surrogates when `canonicalString` receives
a string value, but object member names go directly from `Object.keys` to
`JSON.stringify`. Moving `"a\uD800b"` from a value to a key therefore makes
the same malformed Unicode digestible. RFC 8785's invalid-Unicode failure is
not side-dependent.

Apply the same surrogate validation to every member name before ordering and
serialization. The regression keeps the already-correct value case and adds
the equivalent key case.

## [P1] Negotiation returns an unvalidated local profile identity

`negotiate` schema-validates the peer hello and the welcome body, but returns
the manager's `runtimeProfileDigest` beside the welcome without validating
it. A local policy carrying `"not-a-digest"` succeeds and becomes trusted
negotiation state. Being local does not make malformed profile identity a
certified profile, and this dossier requires exact identities before use.

Validate the complete local negotiation policy, including the profile digest,
before intersecting it with the peer. The focused regression establishes the
digest boundary; future orchestration must not inherit an ad-hoc local-policy
shape which bypasses the frozen constraints applied to the peer.
