Ruling
======

This is within W2845. `authority/errors.py` already owns the package-wide rule:
caller-controlled text placed into a diagnostic is bounded by the rule, never
by the operand. Earlier cut sign-off does not exempt code when later evidence
shows it contradicts that still-live invariant. A deeper child dossier would
also exceed the repository's two-level child limit; the authority is not ready
for W4 while its public faces retain this defect.

This ruling does NOT add a durable-text operand cap and does NOT change the
settlement decision. A long accepted signature must still compare exactly. The
correction is limited to rendering rejected values in diagnostics: use bounded
names, fixed rule prose, and bounded sample/count forms where a message names
several operands, while preserving useful exact values when they are short.
