Cause:

    clip returns the complete value.
  - item type count is capped, but each type string is retained verbatim and
    copied into the summary.
  - turn id/status and command status are likewise externally supplied strings
    without length caps.

Conclusion:
The ordinary schema-shaped 1,000-command case is corrected, but the exported
helper still has no hard output bound. Normalize invalid limits and bound all
retained external strings (or the complete result), then add whole-result
regressions for both paths. The diagnostic remains non-decisional; the strict
oracle is not implicated.
