P1 — the URI splitter is not the frozen URI validator
----------------------------------------------------
The frozen host constructs `new URL(uri)` and then refuses nonempty username or
password. Python `check_uri` calls `urlsplit(uri)` and discards the result.
`urlsplit` is deliberately permissive: it accepts malformed hierarchical URI
authorities that the frozen constructor rejects, and discarding its result also
omits the explicit userinfo/credential check.

Measured comparison:

* `https://exa mple.test/tree`: Python `urlsplit` accepts; frozen `new URL`
  raises TypeError.
* `https://example.test:bad/tree`: Python `urlsplit` accepts; frozen `new URL`
  raises TypeError.
* `https://worker:secret@example.test/tree`: Python `check_uri` accepts even
  though §12 rule 4 and the frozen host refuse durable userinfo.

Retain:

* `test_a_durable_locator_carries_no_userinfo`
* `test_a_splitter_accepting_text_does_not_make_it_a_readable_uri`

The correction must keep the original-text query/fragment checks, reject
userinfo, and close the authority/port syntax that `urlsplit` merely separates
without validating. Calling a permissive splitter is not proof that the build
can safely consume the locator.

P1 — two exported semantic helpers read unowned caller containers
-----------------------------------------------------------------
`check_work_ref` and `check_content_manifest` are imported by
`baton_v12.contracts` and named in its `__all__`; the package docstring says that
exported surface is the promise. Both immediately index their operands under the
assumption that `check_manifest_structure` already performed schema validation.
Direct callers therefore receive raw TypeError/KeyError on malformed values,
and a dict subclass's hostile `__getitem__` executes.

Retain:

* `test_the_exported_work_reference_rule_owns_its_shape_first`
* `test_the_exported_content_rule_owns_its_shape_first`

Give each public function a schema-owning wrapper and keep a private trusted
semantic helper for the already-owned composite path. This preserves one owner
at each crossing without validating nested values twice. If the helpers are not
intended as public operations, shrinking the explicitly published surface needs
a separate ruling rather than leaving unsafe functions under `__all__`.
