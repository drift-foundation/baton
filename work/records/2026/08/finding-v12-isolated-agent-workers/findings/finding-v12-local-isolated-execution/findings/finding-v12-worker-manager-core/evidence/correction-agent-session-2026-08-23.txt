2. THE ONE THAT MATTERS MOST: I CONFLATED TWO ROLES

[P1] EXECUTION OPENED AFTER THE AUTHORITY ASSIGNMENT ENDED. `openAgentSession`
consulted only the assignment cached in the manager's own attempt row, so an
execution session opened cleanly against an assignment the authority had
already fenced and ended.

AND THE REASON I BUILT IT THAT WAY WAS A CASE I WROTE MYSELF. I asserted "no
Baton capability" of the FUNCTION SIGNATURE — no session, no handle — and
called that keeping the rule by construction. It conflated the trusted WORKER
MANAGER, which IS the one Baton authority client and must reproject the
assignment, with the untrusted AGENT ENDPOINT and relay, which are what must
never receive a capability. Removing the manager's handle did not prove
provider isolation. It removed the liveness check the contract requires, and
my own test then defended the hole.

A structural test can encode a misunderstanding as firmly as it encodes a
rule.

CORRECTED. The manager's participant-bound handle is a parameter, read ONCE to
reproject, and the full four-part assignment is compared before the insert.
The rule it replaced is now stated where it actually lives: the handle appears
in nothing the function returns and in no column of the durable row, and a
case asserts both — plus that the handle WAS used, because a reprojection that
never happened would satisfy an absence test perfectly.


3. THE OTHER TWO

[P1] FRESHNESS AND CONCURRENCY WERE TESTED AS ONE RULE. `openAgentSession`
took `MAX(session_epoch) + 1` and inserted unconditionally, so a posture could
hold three simultaneously open epochs — and my freshness case opened exactly
that and called it evidence.

A partial UNIQUE INDEX on `(runtime_attempt_id, posture) WHERE state <>
'closed'` is what refuses now, because a read of MAX followed by a separate
insert is not an atomic allocator across two manager connections. A case
drives it from a SECOND CONNECTION, which no read-then-write check could
refuse. The violation is translated to the frozen
`runtime-observation.duplicate-runtime` pair, and only a UNIQUE violation is —
the same narrowing the observation boundary already carries.

`closeAgentSession` is the only thing that frees a posture, and the freshness
case now drives that terminal transition between same-posture epochs.
`unknown` deliberately does NOT free it: transport ambiguity is where a second
session is most tempting and least safe, and re-identification after it is a
gate this slice has not built.

[P1] THE RETAINED DOCUMENT'S DECLARED SEAL WAS NOT REBOUND. The loader
destructured `document_digest` away and never compared it, so a retained
profile whose every other byte matched its key could carry somebody else's
well-formed seal. TWO OF THREE WITNESSES AGREEING IS NOT AGREEMENT: declared,
recomputed and the key are one fact now.
