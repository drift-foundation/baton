2. THE DESIGN, AND THE THREE SENTENCES IT TURNS ON

COUNTED, NEVER GUESSED AT. 6.1's `other` is an escape hatch with teeth: an
update kind this contract has never seen becomes `other`, keeps the
provider's own string verbatim as diagnostics, and carries NO portable
content. Its bytes are still counted. A relay that guessed would be inventing
agent evidence; one that dropped would report a partial stream as complete.

`other` CARRYING NO CONTENT IS A RULE, NOT A DESCRIPTION. `user_message_chunk`
maps to `other` and arrives WITH content — the relay authored that prompt, so
an echo of it is the transport talking back. A normalizer that passed content
through whenever it happened to be present would quietly make the relay's own
prompt into durable agent evidence.

THE SEAL COVERS THE FRAME, NOT THE OBSERVING OF IT. 6.4 is explicit and the
reason is concrete: `late` and the manager's `observation_seq` are properties
of an OBSERVATION. A retransmitted frame is the same frame, so sealing
lateness in would give one frame observed twice — once before a turn ended and
once after — two digests, making an ordinary duplicate indistinguishable from
a spliced stream. Lateness is decided when the frame is FIRST seen; a
retransmission replays that original observation.

4. THE BOUNDARIES

  seal first        6.4: a consumer verifies the seal BEFORE it reads any
                    other field. A frame whose digest was never checked has no
                    claim on the identity, sequence or duplicate rules below,
                    so `authenticateEvent` runs before any of them.
  identity          the FULL reference per 3.1; a disagreement is
                    runtime-observation.identity-mismatch. An omitted
                    provider id is not agreement.
  duplicates        same sequence + same seal -> replay the ORIGINAL
                    observation, nothing persisted twice. Same sequence +
                    different seal -> integrity.digest, because the transport
                    lied about ordering or the stream was spliced and neither
                    is a merge to attempt. Both sides are sealed, so the two
                    digests ARE the comparison.
  lateness          decided once, at first sight, against the turn's terminal
                    fact. A frame naming no turn is never late — there is no
                    terminal fact for it to be after.
  turn binding      the frame's own turn_id and the turn it is observed into
                    must agree, and that turn must be allocated in this epoch.
  bounds            the profile the session actually opened under pins
                    max_event_bytes; over-limit refuses integrity.limit with
                    no partial action (3.1). A withdrawn profile refuses
                    rather than falling back: a bound nobody can read is not
                    a bound.
  redaction         the complete document is scanned before anything durable.
                    `redacted: true` is a constant in the frozen shape, so it
                    is a claim this boundary has to be able to make.
