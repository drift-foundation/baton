2. THE DEFECT

`maskComments` built its output with `[...text]`. That is a code-POINT array.
The masking loop, `matchingParen`, the whitespace accounting, the operand
reader and every offset this module takes into `text` are UTF-16 code UNITS.
The two index spaces agree only while every character is in the BMP; after
one astral character they differ by one element per astral character.

So an emoji in a comment made every later mask write land one element late.
The joined mask was then shorter than the source AND misaligned with it, and
the structural scanners — which index the mask and quote the source — read a
later valid rule at the wrong offsets and reported it unaccounted.

I introduced this in round 8, in the change that added masking. Rounds 6 and 7
had no mask and no index space to get wrong.


3. THE CORRECTION

  const out = [...text];        ->    const out = text.split("");

`split("")` yields one element per code unit, which is the index space every
scanner below already uses. An astral character becomes its two surrogate
halves; neither is `#` or a quote, so the walk is unaffected by the split and
the mask stays the source's exact length.

The review also asks for the length invariant to be asserted. It is, in
product code rather than only in a test:

  const masked = out.join("");
  if (masked.length !== text.length) throw new Error(...);

RECORDED HONESTLY: that throw is NOT witnessed by any regression and cannot be
from outside the module — it is unreachable while the mask is built correctly,
and the only way to reach it is to reintroduce the defect the split fixes.
What the suite witnesses is the property the review actually asked about: the
audit agrees with the evaluator about astral text. The throw stays as a guard
for a future scanner change, named as unwitnessed rather than counted as
covered.

Quote/comment boundaries are unchanged: the same escape rule, the same quote
tracking, the same `#`-to-newline span, the same whitespace treatment. This
round changes the REPRESENTATION of the mask and nothing about what it masks.
