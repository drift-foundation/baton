## Finding

### P1 — a Proxy that answers successfully is accepted as a document and runs
caller behavior

**Observed.** The options contract admits an ordinary object literal or a
null-prototype record and excludes objects with behavior. `classify()` still
determines that rule by calling `Object.getPrototypeOf` on an arbitrary
object. A Proxy over `{}` can run its `getPrototypeOf` trap, return
`Object.prototype`, then run `getOwnPropertyDescriptor` and return no member.
The manager accepts that behavioral object as an empty options document and
commits the epoch from `prompting` to `unknown`.

The member path has the same underlying defect without the commit: a Proxy
stored as `turnInFlight` returns a plausible prototype, its trap runs during
the refusal, and only then does the boolean check reject it. Translating a
trap that throws does not protect against a trap that successfully authors
the answer.

**Required.** Enforce the stated plain-record boundary without invoking Proxy
traps. Reject a Proxy envelope before prototype/descriptor reflection and
reject a Proxy member before diagnostic classification; both must return
`integrity.schema`, execute no trap, and leave the session axis unchanged.
The Node runtime provides a non-observing discriminator:
`node:util/types.isProxy` identifies live and revoked Proxies without running
their traps. An equivalent non-observing proof is acceptable; another
try/catch around reflection is not, because successful traps are the defect.
Retain both additive regressions.
