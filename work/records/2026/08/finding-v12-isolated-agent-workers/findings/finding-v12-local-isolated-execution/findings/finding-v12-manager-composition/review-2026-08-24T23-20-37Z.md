# W6592 cut A review — exact handshake input types

## [P1] A Boolean satisfies the integer wire pin

`negotiate_acp` uses Python value equality for the caller's
`agent_protocol_version`, so `True` passes a profile pinned to integer `1` and
is returned as a successfully negotiated wire version. The frozen reference's
`!==` comparison is type-strict. Preserve that exact-match contract in Python:
a Boolean is not the integer version it compares equal to.

The additive
`test_a_boolean_is_not_the_integer_wire_version_it_compares_equal_to` currently
fails because no refusal is raised.

## [P1] The claimed exact capability list is neither exact nor necessarily a list

The receiving-boundary inventory says `_offered` owns one exact built-in list
before walking it. In implementation it owns any JSON value, iterates the
result, and filters out non-text entries. A dictionary keyed by all six required
capability names therefore passes. A list containing all six plus an integer,
Boolean, or null also passes after the foreign member is silently erased.

Establish the exact built-in list and establish every member as text before
membership testing. Do not repair this by merely special-casing dictionaries:
the projection that drops non-text JSON is the second half of the same gap.

The additive `test_the_capability_answer_is_one_list_containing_only_text`
currently fails for all four probes.
