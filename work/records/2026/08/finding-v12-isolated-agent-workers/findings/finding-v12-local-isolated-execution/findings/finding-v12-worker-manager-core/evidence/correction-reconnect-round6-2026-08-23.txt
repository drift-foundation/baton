2. I SPENT FIVE ROUNDS MAKING REFLECTION FAIL SAFELY, AND THE HOLE WAS THE
   ORDINARY CASE

Every guard on this primitive assumed a hostile value MISBEHAVES: it throws
from a getter, it throws from a trap, it is not serializable, it revokes
itself. Each round I translated one more failure. A Proxy over `{}` needs none
of that. It runs `getPrototypeOf`, returns `Object.prototype`, runs
`getOwnPropertyDescriptor`, returns no member, and is accepted as an empty
options document -- so caller code RAN and a program COMMITTED the epoch to
`unknown`.

TRANSLATING A TRAP THAT THROWS DOES NOTHING ABOUT A TRAP THAT ANSWERS. The
review says this exactly and it is the sentence I did not have. All five
previous corrections were about the failure mode I could see happening.

So the Proxy test is FIRST and NON-OBSERVING. `node:util/types.isProxy` reads
an internal slot: it identifies live and revoked Proxies alike and runs no
trap. The review is explicit that another try/catch is not acceptable here,
and it is right -- a successful trap simply walks past one. A Proxy is a
PROGRAM WEARING AN OBJECT, and the rule this envelope has always stated is
that a document has no behaviour.

Both paths are covered by the one change because both go through `classify`:
the envelope classifies before `isPlainRecord`, and a member value classifies
inside `describe`. That is the shape the fourth correction put in place -- one
place the reflection happens -- and it is why this fix is one guard rather
than two that have to agree.
