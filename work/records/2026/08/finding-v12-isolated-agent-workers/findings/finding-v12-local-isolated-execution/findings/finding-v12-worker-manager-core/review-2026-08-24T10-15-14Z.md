## Findings

### P1 — a metaclass `__name__` descriptor still executes

`contracts.errors.type_name_of` calls
`type.__getattribute__(kind, "__name__")`. This skips a metaclass
`__getattribute__` override, but it still resolves and invokes a data descriptor
installed as `__name__` on that metaclass. A rejected class therefore runs
caller code while the manager is only trying to name it. Read the built-in
type descriptor directly (for example, bind `type.__dict__["__name__"]` to the
class) or use an equivalently non-dispatching primitive.

Regression:
`tests.manager.test_pod.ABehaviourBearingContainerNeverEnters.test_naming_a_type_does_not_run_a_metaclass_descriptor`.

### P1 — the authoritative refusal pairing is not frozen

The new `_PAIRING` value is private, but its outer container is a regular
mutable dict. A caller that reaches the module can replace `_PAIRING["policy"]`
and immediately construct an invented pair. Privacy is not an isolation
boundary inside one Python process, and the implementation comment itself
promises that this value is frozen all the way down. Make the authoritative
outer mapping immutable as well as its member sets.

Regression:
`tests.manager.test_frozen.ThePairIsCheckedWhereItIsRaised.test_the_authoritative_pairing_is_actually_frozen`.

### P1 — the exported validation helper executes a caller-supplied validator

`contracts.validate.validate_against` is exported and accepts an arbitrary
object as `validator`, then invokes its `iter_errors` method after taking
ownership of the document. This creates a new caller-program execution seam in
the trusted contracts surface. Keep the generic helper private, or restrict
the public operation to authority-owned validator identities without invoking
an unapproved object.

Regression:
`tests.manager.test_validate.TheLibraryDecidesTheContract.test_a_caller_supplied_validator_is_not_executed`.

### P1 — caller mutation of a readable schema rewrites runtime validation

The fixed `_WORKER_CONTROL` and `_AGENT_SESSION` validators retain the same
mutable dicts exported as `WORKER_CONTROL` and `AGENT_SESSION`. Replacing
`WORKER_CONTROL["oneOf"]` therefore causes a previously valid envelope to
refuse. The product may expose a readable schema, but runtime authority must be
constructed from a private deep copy or another caller-inaccessible frozen
representation.

Regression:
`tests.manager.test_validate.TheLibraryDecidesTheContract.test_mutating_the_readable_schema_does_not_change_validation`.

### P2 — canonicalization bypasses the owned shape limits

`contracts.canonical.canonicalize` enforces exact data types and scalar
restrictions, but does not enforce `MAX_DEPTH` or `MAX_MEMBERS`. Documents that
`own` refuses as too deep or too wide can therefore acquire canonical bytes and
digests through the public canonical surface. Apply the same frozen ownership
bounds at canonicalization entry before recursion; do not let extreme depth
escape later as raw `RecursionError`.

Regression:
`tests.manager.test_canonical.WhatCannotAcquireADigest.test_canonicalization_enforces_the_owned_shape_bounds`.
