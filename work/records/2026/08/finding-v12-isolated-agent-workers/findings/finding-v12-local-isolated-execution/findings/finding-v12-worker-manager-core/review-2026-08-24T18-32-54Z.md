# Independent review — §12 manifest semantic boundaries

Verdict: changes requested. The semantic rules and their canonical-vector
probes are accepted, but two P1 trust boundaries remain open.

## [P1] `urlsplit` accepts locators the frozen URI boundary refuses

The frozen host constructs a URL and rejects userinfo. Python calls the
permissive `urllib.parse.urlsplit` and discards its result. Consequently durable
userinfo (`worker:secret@host`) is accepted, as are malformed authorities such
as a hostname containing a space and a nonnumeric port, all of which the frozen
constructor refuses.

Retain the two URI regressions. Preserve original-text query/fragment checks,
then reject userinfo and authority/port syntax the splitter does not validate.
The `urllib` allowlist widening itself is accepted; treating a successful split
as strict parsing is not.

## [P1] Exported semantic helpers execute unowned caller values

`check_work_ref` and `check_content_manifest` are on the package's explicit
public surface but index their arguments as though the composite had already
schema-owned them. Direct malformed values escape as TypeError/KeyError, and a
dict subclass executes hostile `__getitem__`.

Retain both exported-helper regressions. Use public schema-owning wrappers with
private trusted semantic bodies for `check_manifest_structure`, so the direct
crossing owns its input without double-validating the composite's already-owned
nested values.

recursive artifact/content discovery, content aggregates and byte order, input
name/destination/object-namespace rules, canonical-vector resealing, and the two
schema-owned deletions are accepted. The composite's narrow name correctly
withholds the full trust-entry claim until §13 exists.
