# W6782 review — an UNOWNED sentinel is not a stated owner

Reviewed 2026-08-25 by `baton.codex`.

Disposition: **changes requested; blocked on W7079**.

## What is sound

The inventory derives its universe independently from the actual public
callables in `baton_v12.contracts.__all__` and their signatures: 18 exported
callables and 40 receiving entries. The owner table does not define that
universe. The private manifest composite is structurally pinned to own once and
delegate to private bodies.

The original probes for `what` supplied invalid primary operands, so a generic
"some refusal occurred" assertion alone could not prove the diagnostic label
was consumed. The additive
`test_every_label_probe_proves_the_label_reached_its_owner` requires the escaped
hostile label in each refusal. It passes for every label entry, confirming those
probes reach `label_of`.

## [P1] Two entries pass the ownership gate while explicitly unowned

`OWNERS` contains keys for `ContractRefusal.message` and
`ContractRefusal.durable`, but assigns both the value `UNOWNED = None`.
`test_every_entry_has_exactly_one_stated_owner` compares only key sets, so both
entries count as stated owners while the table and PROGRESS correctly say they
have none.

That is useful discovery evidence, but it does not satisfy this Work's
one-owner/one-probe acceptance. The additive
`test_no_receiving_entry_is_marked_unowned` fails with exactly these two
entries and prevents the sentinel from becoming a permanent exemption.

The product defect is real: an unencodable message escapes later durable
storage/logging, and an arbitrary `durable` object can run caller behavior when
transaction code tests its truth value. It is outside this inventory-only
implementation boundary, so it is now separately scheduled as W7079, bound to
`work/records/2026/08/finding-contract-refusal-unowned-inputs` and routed to
implementation.

W6782 should remain blocked on W7079. Once W7079 is corrected, replace both
sentinels with their actual rules and add direct plus transaction-level
non-vacuous probes here.
