## Findings

### [P1] The adopted refusal owner is opened by its public vocabulary

`boundaries._sealed_refusal` enforces the supposedly closed category/code pair
through exported mutable `ERROR_CODES`. The contracts layer deliberately keeps
that value readable but non-authoritative: its existing regression proves a
caller may append `caller-invented` there without opening `ContractRefusal`'s
private frozen pairing. With that same mutation, an invented persisted pair
passes the new row owner and then escapes replay as `AssertionError` from
`ContractRefusal`.

The rule also performs `category not in ERROR_CODES` before establishing that
category is text. An exact-POD list category therefore escapes the adopted
boundary as `TypeError: unhashable type: 'list'`. Owning a semantic field means
typing it before operations that assume the type, and a closed pair cannot be
owned by a value callers can widen.

Retain both additive adopted-replay regressions. Give the seal one authoritative
semantic owner shared with the contracts layer, without consulting the mutable
readable vocabulary and without reaching the assertion-only constructor until
the input is already owned.

### [P1] Public revival still owns only the seal's member names

`revive_refusal` remains an exported receiving boundary over caller text. It
adopts JSON and checks the exact four names, then passes their contents directly
to `_revived`. A list category escapes as `TypeError`; a cross-category pair
escapes as `AssertionError`; an integer message is accepted into a
`ContractRefusal`; and a false durable marker is silently rewritten to true.

The centralized inventory confirms the model gap: it contains only
`('caller', 'store.py:revive_refusal', 'sealed')`, with no semantic entries for
category, code, message or durable. PLAN 4cf split public revival from trusted
replay correctly, but the public half never acquired the field contract now
added only to the adopted half.

Retain the four-subtest public regression. Model semantic members of
caller-supplied structured values as entries, not only injected and adopted
ones, and route public revival through the same closed seal semantics exactly
once.
