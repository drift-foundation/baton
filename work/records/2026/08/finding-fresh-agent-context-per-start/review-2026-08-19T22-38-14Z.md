# Slice 1 review round 3 — signed off

No remaining slice-1 findings.

Render templates now participate in preflight as first-class service
configuration. Each template is read once during manifest load; its context
references receive the same existence and lifecycle-order validation as
command, environment, required-path, and working-directory references; and
the later render uses the exact body that was validated. An unreadable or
non-UTF-8 template therefore refuses before launch, and a content change
between load and context minting cannot bypass preflight.

The round-2 reviewer regression passes unedited. Added coverage also proves a
late context hidden in a template refuses, render-to-render composition is
explicitly unsupported, and a context command cannot alter the validated
render body before it is written.
