== P1b. The report no longer travels on a channel the runner owns ==

  The probe writes its report to a file the PARENT nominates. Proof that
  the channel is independent of reporter and isolation:

    --test-isolation=process  ℹ pass 6 ℹ fail 0
    --test-isolation=none     ℹ pass 6 ℹ fail 0
    NODE_OPTIONS=--test-reporter=dot  ......

  And the child's own stdout is no longer consulted at all:
    report file: 4 roots, tests=['creates', 'intended-failure', 'after-failure'], reachedIntendedFailure=True

  The parent now diagnoses spawn error, signal, a missing report file, a
  malformed report and an incomplete one as SEPARATE named outcomes, each
  carrying exit status, signal, stdout and stderr — so a denied spawn
  cannot look like a clean run, which is what made the reviewer's sandbox
  failure indistinguishable.

  'It failed for the intended reason' no longer depends on output either:
  the probe records reachedIntendedFailure immediately BEFORE the assertion,
  so the parent can tell 'reached it and died there' from 'died elsewhere'.
