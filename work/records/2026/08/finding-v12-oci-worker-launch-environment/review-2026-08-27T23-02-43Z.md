## [P0] The implementation is the contract that the dossier superseded

The live decision in `FINDING.md` requires one versioned UTF-8 JSON document,
authored by the manager, mounted read-only at fixed
`/run/baton/launch.json`, and strictly validated by the reference worker. It
also explicitly forbids the four `BATON_WORKER_*` environment variables as a
fallback or compatibility path.

The submitted implementation does the inverse:

- `attempts.request_runtime_start(..., environment=None)` introduces the
  caller-supplied environment operand and merely carries it through.
- `oci.run_vector(..., environment=None)` translates it into four `--env`
  arguments; `environment=None` is explicitly tested as legal.
- `Lifecycle.launch` invents session, contract, and role values in the test
  fixture rather than proving manager authorship.
- `v12/worker/baton_worker.py` remains unchanged and continues to read the
  legacy `ENVIRONMENT` variable set. It has no fixed launch-document reader or
  strict document validator.
- The positive Docker test proves only that the retired environment transport
  makes the old worker exit zero.

This is not a narrow review defect. No live plan item after revalidation is
implemented, and retaining the added environment seam would create the exact
compatibility path the superseding decision prohibits.

## Required correction

Implement the current PLAN 2–5 boundary end to end:

1. Pin one exact schema/version and document bounds in the dossier before code
   changes proceed.
2. Have the manager author the complete five-member document and expose only a
   typed launch-document capability to the adapter.
3. Materialize one manager-owned regular read-only file and mount it read-only
   at the fixed target, without an environment fallback or arbitrary mount
   channel.
4. Make the worker perform a bounded, no-follow, descriptor-regular read and
   closed validation before any agent execution; reject missing, malformed,
   wrong-version, unknown-field, mutable/non-regular, secret-bearing, and
   legacy-environment-only starts.
5. Replace the retired environment tests and mutation harness with unit,
   failure, mutation, and real-engine evidence for the document contract.

The older implementation evidence should remain as superseded history, not be
silently rewritten into evidence for a design it never exercised.
