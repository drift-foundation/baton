## Result

**Changes requested.** The completed-receipt rule is correctly landed in the
frozen schema, shipped validation path, prose and migrated fixtures. The
canonical invalid vector that claims to prove that rule is vacuous, however,
and the design model duplicates the schema-owned shape rule despite stating
that it models only invariants JSON Schema cannot express.

## Findings

### [P1] The new invalid vector does not test a missing completion binding

`result-completed-without-its-completion-envelope` patches
`completion_manifest_digest` to `null`. That leaves the member PRESENT, so the
conditional `required` rule succeeds and the result branch instead refuses
`None is not of type 'string'`.

The vector still passes because its expected text is only `required` and the
test flattens every error from the top-level schema's `oneOf` over all document
kinds. The malformed result produces 112 messages containing `required` from
unrelated branches, any one of which satisfies that expectation. Thus the
reported canonical invalid-vector coverage does not reach the rule it names.

The additive
`test_the_completed_receipt_vector_reaches_its_named_rule` validates the result
branch directly and fails: its messages are the null type error and a derived
unevaluated-properties error, not
`'completion_manifest_digest' is a required property`.

Make the vector actually omit the member and require that exact diagnostic.
The smallest data-only route is a valid non-completed receipt without a digest,
then an invalid vector that changes only its disposition to `completed`. That
avoids inventing deletion syntax for the vector patch language.

### [P2] The semantic model duplicates a schema-owned shape rule

`contract_model.py` opens by saying it intentionally models “only the semantic
invariants that JSON Schema cannot express.” `_validate_result_manifest` then
repeats the conditional required-member check, and `validate_manifest`
dispatches to it. Under the model's schema-first test harness the semantic
branch cannot be the owner of a missing-member refusal: the schema has already
refused it.

Keep the requirement in the frozen schema and prove that exact branch with the
new regression. Remove the duplicate semantic function/dispatch. The
cross-document rule that cannot be expressed locally — bind any envelope that
was actually validated regardless of eventual disposition — remains normative
in §8.4, observable in conformance, and owned downstream by W6634.
