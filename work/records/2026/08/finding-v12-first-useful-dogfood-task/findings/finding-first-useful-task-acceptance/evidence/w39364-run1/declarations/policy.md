# W39364 run 1 — deployment policy

The umbrella posture for one supervised dogfood attempt on a private box.

enumerated by the six policies beside this one; anything not enumerated is not
granted. The attempt is supervised: a human authorized the credential source
and the network posture explicitly (M50427, M51386), and neither was inferred.

an authorization to run unattended, to widen any policy below, or to treat
these digests as a production baseline.
