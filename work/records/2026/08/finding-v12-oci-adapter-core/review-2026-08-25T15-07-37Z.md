## [P0] Absence prose can combine two unrelated identities into death evidence

`_absent_prose` asks only whether the requested runtime appears anywhere in
stderr and whether an absence phrase appears anywhere in the same text.  It
does not require the absence sentence to name that runtime.  Consequently

    Error: No such container: runtime-2; request was for runtime-1

reports `runtime-1` as `absent`.  This is the exact unsafe branch the earlier
review required to close: unrelated engine prose can become death evidence and
allow the manager to release an assignment whose runtime may still exist.

Additive regression:
`AbsenceIsProvedRatherThanInferred.test_an_absence_sentence_for_another_runtime_is_not_this_one_absent`.
Pin and parse each supported engine's complete exact-identity absence form;
mere co-occurrence in one diagnostic is not association.
