## Findings

### [P1] RFC 3339 fractions are silently truncated to microseconds

The approved grammar and `_RFC3339` both allow one or more fractional-second
digits. `datetime.fromisoformat` accepts those digits but its value has only
microsecond precision. `_export_instant` consequently maps both:

```text
2026-08-27T00:00:00.0000001Z
2026-08-27T00:00:00.0000009Z
```

to:

```text
2026-08-27T00:00:00.000000Z
```

Those are different instants and therefore different half-open range bounds.
Even though current Work timestamps have millisecond precision, collapsing the
operands silently changes the question and makes two distinct approved scopes
indistinguishable in JSON and DOT metadata.

Preserve the arbitrary fraction independently of `datetime` while using the
parsed whole-second/offset portion for calendar validation and UTC rollover.
Canonicalize equivalent fractions (for example `.1` and `.10`) without
discarding significant digits.

Additive regression:
`test_rfc3339_fractional_instants_do_not_collapse_at_microseconds`.

### [P1] Renderer ownership still does not include member types

`_owned_node` and `_owned_edge` prove that fixed members are present, then the
shared validator proves graph topology. Neither proves the values have the
fixed structured types before Python truthiness/stringification or downstream
methods give them meaning.

Two concrete malformed renderer inputs show the gap:

- `selected="false"` is truthy, so `_node_statement` emits
  `baton_scope="selected"`; and
- `title=7` escapes as `AttributeError` at `.encode()` rather than the promised
  Baton refusal.

Validate every fixed node/edge member's type and nullable domain before graph
semantics. Refuse with `WorkError` naming the exact member before any DOT is
composed. This should cover the whole fixed schema rather than two one-off
guards; the regression names the two values that currently change behavior.

Additive regression: `test_the_renderer_owns_structured_member_types`.
