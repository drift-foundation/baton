=== 3. THREE THINGS THE TREE SAID THAT THE DESIGN DID NOT

  Each was found by driving the approved design against the real
  authority rather than by reading it, and each changed a test.

  --- [1] THE AUTHORITY STORES HOSTILE TITLES THAT LOOK UNSTORABLE
  validate_subject refuses a literal newline or carriage return in a
  Work title. It refuses NOTHING ELSE that this export has to survive:
  a bare TAB, a NUL, a right-to-left override and U+2028/U+2029 are all
  storable. U+2028 is the sharpest — it IS a line break to a great many
  consumers, and the single-line check does not see it. So the
  renderer's visibility rule is load-bearing for REAL titles, not
  hypothetical ones. The two the authority refuses are still driven at
  the renderer, because a later relaxation of the title rule must not
  silently become a DOT-injection defect.

  --- [2] THE AUTHORITY PERMITS FEWER PARALLEL RELATIONS THAN RULED
  FINDING.md says any of the four families may coexist on one pair.
  Driven for real, the reachable set is narrower:
      containment + dependency  refused as a required-edge cycle
      follow-up + dependency    refused: a follow-up predecessor is closed and
                                a new blocker must be open
      containment + duplicate   refused: a parent cannot close holding an open
                                child
      dependency + duplicate    REACHABLE -- A blocks B, then A closes as a
                                rejected duplicate of B
  Two parallel edges is all the non-strict argument needs, and the case
  now uses the reachable pair rather than an invented one. The renderer
  is separately held to four, because a later change to the authority
  must not become a change to every previously exported document.

  --- [3] A MODULE-SCOPE NAME COLLISION, WHICH WAS MINE
  projection.py already had a _graph_node for the bounded dependency
  NEIGHBOURHOOD. I appended a second definition of that name for the
  export. Python rebinds silently: W24755's own suite passed while
  EIGHTY-EIGHT dependency-graph cases failed with a TypeError.

=== 4. TWO CLARIFICATIONS INSIDE THE RULING, NOT AGAINST IT

  --- the DOT graph attributes had to carry the approver's range
  DOT v1's attribute list predates the changed-from/changed-until
  ruling. The determinism promise is that one authority, one snapshot
  and one SCOPE give one document — so a scope operand the document did
  not spell would let two different questions produce identical bytes.
  baton_scope_changed_from and baton_scope_changed_until are emitted,
  '*' when absent, and a case proves two scopes over one snapshot
  differ.

  --- 'scope=selected|context' versus 'a baton_* per node member'
  FINDING.md says both. They conflict for one member. The explicit
  spelling wins, because it is the more specific instruction; the
  mapping is total, so 'selected' is still recoverable, and a case
  asserts every other member has its own baton_* attribute.

    the projection's status default -- the CLI grammar carries its own
      default and passes it explicitly, so changing work_graph's changed
      nothing any case could see. BOTH are now asserted, because a caller
      reaching the projection directly gets the projection's.
    
    the graph attribute sort -- the dict literal was ALREADY written in
      sorted order, so removing sorted() moved no byte. Fixed at the rule
      rather than the case: both attribute lists now go through one owner,
      so the cases that hold the bracketed lists hold the graph block too.
    
    the literal 'null' -- nothing asserted it, so rendering absent members
      as '' passed everything. Now asserted in both directions.
    
    one write of a whole document -- the refusal cases prove stdout is EMPTY
      when the PROJECTION refuses, but by then the renderer has not run. A
      streamed prefix was invisible to all of them. The write itself is now
      observed: exactly one call, opening and closing the digraph.
    
    the interleaved-writer case -- it took a fixed twelve exports, and over
      a small database all twelve finished before the writer's first commit.
      It was a consistency proof about a QUIET store that would have passed
      for an exporter with no snapshot discipline at all. It now reads until
      the writer has actually moved the authority three times, under a
      deadline.

    weakening a test — but it is an edit to existing assertions and is
    named here rather than left to be discovered.

    new module-scope collision rule was added there too. Both are
    additive.
