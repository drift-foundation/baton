## Findings

### [P1] The range parser accepts non-RFC 3339 spellings

`projection._export_instant` delegates its grammar to
`datetime.datetime.fromisoformat`. Python accepts a superset of RFC 3339. The
reviewer reproduced acceptance and UTC normalization of:

```text
2026-01-01 00:00:00Z
2026-W01-1T00:00:00Z
20260101T000000Z
```

The approver ruled that both operands accept only timezone-bearing RFC 3339.
Validate that grammar explicitly before parsing, preserve offset-to-UTC
normalization, and keep refusal-before-DOT-output behavior.

Additive regression:
`test_time_bounds_accept_only_rfc3339_spelling`.

### [P1] The pure renderer does not independently validate graph integrity

The module contract says the renderer owns its structured input because it may
be called by something other than `projection.work_graph`. Its validation is
currently shallow: `_envelope` checks outer container shapes and
`_edge_statement` checks only the relation enum. The authoritative semantic
checks remain solely in `projection._export_validate`, which the renderer does
not call.

As a result, `render_work_graph_dot` emits complete-looking DOT for:

- an exact duplicate typed edge;
- an edge whose endpoint has no node; and
- a relation whose predicate belongs to another relation.

Run equivalent semantic validation at the renderer boundary before composing
any statement. Reuse one validator if appropriate; the requirement is one
enforcement on every renderer input, not duplicated rule text.

Additive regression:
`test_the_renderer_revalidates_edge_integrity`.

### [P1] `selected` lost its fixed `baton_*` attribute

The approved format requires `scope=selected|context` in the readable node
representation and a `baton_*` string for every structured node member. These
requirements are complementary, not conflicting. Current `_node_statement`
skips `selected` and emits only `baton_scope`.

Retain `baton_scope="selected|context"` and also emit
`baton_selected="true|false"`. That preserves the projection's exact boolean
without requiring a format-specific reverse mapping.

Additive regression:
`test_selected_keeps_its_ruled_baton_member_beside_scope`.

### [P2] Store-dependent scope validation sits outside the named snapshot

`work_graph` calls `_export_scope` before entering `_read_snapshot`, while
`_export_scope` queries `teams`. The graph rows and sequence are coherent, but
the configured-team fact used to admit the scope is read at another instant.
Move that store-dependent check under the same snapshot; syntactic operand
validation and full rendering can still refuse before stdout.
