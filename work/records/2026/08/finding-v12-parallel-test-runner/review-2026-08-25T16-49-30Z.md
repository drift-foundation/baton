## New finding

### R4 — High: a signal after spawn but before registration orphans the whole shard

**Confirmed.** `Run.drive()` creates the shard process at
`v12/python/tools/parallel_test.py:471`, then registers it in `self.live` and
`self.groups` on lines 472-473. The installed asynchronous signal handler can
run after `Popen` returns but before either registration. `shutdown()` then
sees zero live shards and zero groups, removes the result root, and exits 130
while both the shard leader and its descendant continue running.

Unlike R1-R3, reordering cannot close this interval because the `Popen` object
must exist before it can be registered. This remains within W9707's explicit
signal-cleanup boundary and should not be deferred to separate Work.

**Regression.** The additive
`AnInterruptLeavesNothingBehind.test_an_interrupt_after_spawn_cannot_cross_the_registration_gap`
at `v12/python/tests/tools/test_parallel_runner.py:556` wraps the real
`Suite.spawn()`. After the run-shard process starts, the wrapper waits until
that shard's TERM-ignoring descendant publishes its PID, records the leader's
PID, and sends the runner a real `SIGINT` before returning the child for
registration. The regression owns final cleanup of both witnesses.

**Required correction.** Proceed with the implementer's proposed deferred
signal handling. The asynchronous handler should record the pending signal and
return without inspecting or mutating scheduler state. The scheduler must
register every successfully spawned child and its group before checking that
pending state at a safe point; it can then enter the existing bounded cleanup
path and exit with the signal result. Apply the same safe-point rule around all
spawn/retire state transitions so the correction closes the family rather than
only this injected line.

Revalidate signals that arrive while the scheduler is idle and while final
cleanup is running so none are silently converted into a successful exit. A
second signal need not bypass the bounded cleanup. The new regression, all
prior cleanup regressions, and the complete runner-test module must pass before
another review.
