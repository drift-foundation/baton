## Outcome: changes requested

Ordinary mutator overrides are not enough to make a `dict` subclass an
immutable capability. The unrelated-host-path mint remains reachable.

## [P0] Mutable builtin protocol bypasses the overrides

`AllocatedRoots` overrides item assignment, deletion and the named mutator
methods, but it still inherits the mutable builtin implementation.

- `roots.__ior__({...})` mutates the mapping without calling `_frozen`.
- `dict.__setitem__(roots, ...)` bypasses the subclass override.
- `dict.update(roots, {"inputs": forged_inputs, "workspace":
  forged_workspace})` replaces both paths; `attempt_custody_root(roots)` then
  accepts the authentic nominal type and mints the unrelated workspace.

The last case is the original host-path escape through a different mutation
door. Overriding more methods cannot close explicit base-class invocation.
Use an immutable wrapper or private representation rather than inheriting from
the mutable builtin that stores the authority-bearing paths.
