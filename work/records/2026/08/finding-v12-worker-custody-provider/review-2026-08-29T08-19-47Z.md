## [P0] `attempt_custody_root` launders caller paths into capabilities

`attempt_custody_root(roots, which)` says `roots` is the answer from
`assignment_workspace`, but it receives an ordinary mapping and proves only
that `inputs` and `workspace` keys exist. A caller can supply the authentic
inputs path beside any unrelated absolute `workspace` path; the function
canonicalizes it and returns a valid `CustodyRoot`. `custody_vector` then
trusts that nominal type and binds the unrelated directory.

The `result` arm creates a second escape available to the ended worker. The
workspace root is worker-writable, so the worker can leave `result` as a
symlink to any host path the engine can resolve. `os.path.isdir` follows the
link, `os.makedirs` is skipped, and `_real` resolves the target before minting
it. The two added daemon-free regressions both fail because no
`ContractRefusal` occurs.

Required correction: derive/reopen the exact attempt root through a durable or
nominal manager-owned authority that an ordinary mapping cannot imitate, and
prove the selected entry is the exact no-link directory owned by that attempt.
Never turn `realpath` of a worker-controlled alias into a mount capability.

## [P1] Directory symlinks disappear from inspect and survive discard

The corrected walk removes symlinked directories from `directories` before it
yields the current directory. This correctly prevents traversal, but also
removes the link object from `every()`. Consequently `inspect` returns an
empty entry list for a root containing one directory symlink, and `discard`
reports success while leaving the link present. Both added regressions fail.

Every object means the link itself remains observable and removable while its
target remains untouched. Preserve directory symlinks as entries, exclude
them only from descent, and prove both halves.

## [P1] `read` and `archive` return descriptions, not the named custody

`read` consumes the whole file but returns only a replacement-decoded 4096-byte
head and hash. The manager cannot recover bytes beyond the head or exact
non-UTF-8 bytes. `archive` returns paths, sizes, hashes and a tree digest, but
no file content or locator for a preserved copy. A manifest that proves bytes
once existed is not an archive of those bytes.

The implementation needs explicit manager-owned output contracts that deliver
complete read content and preserve recoverable archive content. The current
`handle.read()` also loads an arbitrary worker file wholly into a helper
limited to 512 MiB; use streaming and explicit bounds/output custody so large
objects do not turn the unconditional act into an OOM exit.
