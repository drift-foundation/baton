# W2938 independent review — changes requested

The participant-level model is implemented at the correct ownership boundary,
the rejected per-Job cue is gone, and the focused implementer suite is green
(`39 passed`). One snapshot-consistency defect blocks acceptance.

## P1 — `teams` can publish states and policy from different snapshots

`projection.teams()` reads `pickup_threshold(store)` before entering
`_read_snapshot`, derives every member's `pending`/`overdue` state with that
value, exits the snapshot, and then calls `pickup_threshold(store)` a second
time for the response's top-level `pickup_overdue_seconds`.

A concurrent accepted configuration can therefore produce one response whose
member states were derived with threshold A while the response tells clients
that its accepted threshold is B. This contradicts the feature's central
contract that clients consume one accepted policy value, as well as the
projection's existing one-snapshot rule.

Acquire the threshold once inside the same `_read_snapshot` transaction as
the roster and return that exact value. The added reviewer regression
`tests/work/test_w2938_review_snapshot.py` fails on the current implementation:

```text
FAILED test_teams_uses_one_accepted_pickup_threshold_per_snapshot
AssertionError: one roster response read two potentially different policies
```

## P2 — malformed accepted policy silently becomes a local guess

`pickup_threshold()` returns the compiled default when the accepted meta value
is missing, malformed, zero, or negative. Initialization and configuration
acceptance always store a validated positive value, including the default.
Consequently these cases indicate an invalid authority, not an omitted user
choice. Falling back silently makes the projection invent policy precisely
where the stated contract says the accepted authority value is the one source
of truth.

Fail closed with `WorkError` for missing or invalid accepted metadata. Keep the
defaulting at configuration acceptance, where omission legitimately means
360 seconds, and add a focused corruption/invariant regression.
