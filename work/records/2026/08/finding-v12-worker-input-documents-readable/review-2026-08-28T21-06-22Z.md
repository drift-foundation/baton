that constant. `compose_input_root` writes both documents and returns without
freezing the directory. The submitted evidence confirms the actual host root
is still uid/gid 1000 mode `0775`.

Consequently the manager owner, and any member of a writable gid 1000, can
unlink or replace the `0444` documents through the writable directory. A
read-only container bind prevents the worker from writing; it does not prevent
the host from replacing a bind-mounted file underneath that worker. This
contradicts the acceptance that the input directory/documents remain
non-writable and non-replaceable and the implementation's claim that the host
mode prevents a later manager mistake from rewriting claim evidence.

directory behavior, so the stated 6/6 result overclaims one guard.
