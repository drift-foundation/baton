artifact locator is openable, but its only positive check is

directory. A directory with mode `000` therefore passes `_kept` even though
the documented independent diff and verification rerun cannot traverse it.
`_ended_however` can consequently set `resolved=True` for a retained candidate
the operator cannot review.

   `file:///tmp/w51473-inaccessible.m9YE06`; `evidence["unresolved"]` remains
   empty.
3. `os.listdir("/tmp/w51473-inaccessible.m9YE06")` raises
   `PermissionError: [Errno 13] Permission denied`.

locator exists after completion *and supports* the documented independent diff

claim ("PROVED to be openable") false.

with failures converted to an unresolved reason. Add a negative regression
using an existing directory that cannot be opened; retain the positive real
Docker test that performs the independent diff and verification rerun after
the command returns. The exact temporary reproduction path above was left in
