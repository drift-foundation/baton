1. REVALIDATED AGAINST THE PINNED SDK, NOT AGAINST EITHER ARTEFACT

The ruling required exactly this and it is worth doing rather than assuming,
because the whole conflict is two frozen documents disagreeing.

  @agentclientprotocol/sdk 1.3.0, dist/schema/types.gen.d.ts

    type ToolKind = "read" | "edit" | "delete" | "move" | "search"
                  | "execute" | "think" | "fetch" | "switch_mode" | "other"

    ToolCall        kind?: ToolKind
    ToolCallUpdate  kind?: ToolKind | null

Permitted, never required — which is the ruling's "portable but optional",
confirmed rather than inferred. The SDK's own comment on the member is "Helps
clients choose appropriate icons and UI treatment", which is the
presentation-only boundary the ruling draws.

The ten values are exactly the ten the ruling names, in that order.

3. ONE SUPERSEDED ASSERTION, MARKED WHERE IT STOOD

v12's "a tool call carries the provider's id and ONE of ACP's four" ended with
an assertion that a supplied `kind` must be DISCARDED. I wrote that during the
event slice precisely because the two frozen artefacts disagreed and I would
not pick a winner. W543 picked. The assertion is replaced with the copied
view, and the comment above it says what it used to require and on whose
authority it changed.


4. REGRESSIONS

Model, five new cases: every one of the ten copied; the vocabulary compared
against the pinned list; absent omitted for a missing member, an explicit
null, and a RICH update carrying a title, a tool name, a command and a status
— because "absence does not become other" is the inference that would look
most reasonable; six invalid values refused; and the id/status rules
preserved.

v12, four new cases: all ten copied across both tool-call kinds; absent
omitted in the same three shapes; eight invalid values refused; and a kind
carried through sealing into the durable frame, which is the half the old
`additionalProperties: false` made impossible. That last case also asserts the
field DECIDED nothing — the event's own kind still comes from the section 6.2
mapping and no column carries the tool kind, which is how "no permission,
policy, tool authority, turn outcome or disposition" is implemented: nothing
reads it.
