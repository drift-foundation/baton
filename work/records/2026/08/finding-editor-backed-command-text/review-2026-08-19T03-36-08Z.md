## Finding

`Console._author_prose()` handles editor launch failures and nonzero exits,
and its `finally` removes the temporary file, but it does not catch
`KeyboardInterrupt`. A terminal SIGINT commonly reaches Baton while it is
waiting for the foreground editor. `_command_key()` has already closed the
command bar before calling `execute()`, so the exception propagates through
the TUI instead of restoring the ruled draft.

The additive regression
`test_an_interrupted_editor_restores_the_draft_and_cleans_up` reduces this to
`subprocess.run()` raising `KeyboardInterrupt`. On the reviewed tree pytest is
itself interrupted and no test completes. The correction must convert that
path into a visible safe cancellation, preserve the command/caret, remove the
private file, and leave authority bytes unchanged.
