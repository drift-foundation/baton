## [P1] The nominal held projection is still caller-forgeable

`recover_abandoned` is exported and still accepts `state=`. The new guard
requires `type(state) is _HeldProjection`, but `_HeldProjection` is an ordinary
module attribute with a public constructor. A direct caller can therefore wrap
the forged dictionary in the accepted nominal type.

The retained `/tmp/w55758-review-round11-probe.py` creates a real fixed
generation-1 attached attempt, supplies generation-2 grants, constructs
`dogfood_operator._HeldProjection` over a forged generation-2 projection, and
calls the exported operation. Current result:

```text
{"cleanup": "retained", "manager_generation": 1,
 "record_generation": 2, "runtime_state": "absent"}
```

This is the original defect again: generation 1 is ended while the recovery
record publishes generation 2. The new regression tests only the rejected raw
dictionary and therefore cannot catch the accepted wrapper.

Remove the caller-supplied state boundary from the exported operation. It must
perform its own manager read and exact hold. The documented command may carry
one observation through a private composition helper, but an importable Python
class is not an unforgeable capability and must not authorize external state.

## [P1] Zombie evidence still discards each candidate's observed state

`OciAdapter.observe` now carries `candidates` as a tuple of IDs only.
`_reported_zombies` consequently assigns every non-target candidate the
literal state `unidentified` and copies the target observation's `why`. It
does not preserve the state record the engine returned for that candidate.

The same retained probe supplies one mismatched inspection document with
`Id: some-other-runtime` and `State.Running: true`. The resulting zombie is:

```text
{"runtime_id": "some-other-runtime", "state": "unidentified",
 "targeted": false,
 "why": "the engine answered about 'some-other-runtime' and this asked about 'runtime-1'"}
```

PLAN item 53 and M60437 require the exact locator, observed state and reason
per runtime. Carry a closed structured candidate observation, validate its
state at `observe`, and assert the mismatched and multi-candidate reports keep
each candidate's own state and explanation. Do not reconstruct those members
from the expected target.
