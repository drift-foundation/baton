W641 — one ACP client-capability representation
Date: 2026-08-23. Implementer: baton.claude.
Implementing the confirmed ruling; no review to answer.


1. THE RULING WENT FURTHER THAN MY WORKAROUND

I raised this during the handshake slice and, on that review's instruction,
split the concept into two NAMED representations: ACP_WIRE_CLIENT_CAPABILITIES
for the transport and NORMALIZED_CLIENT_CAPABILITIES for the durable profile.
That was the right thing to do while the artefacts disagreed and the owner had
not ruled.

The ruling did not ratify the split. It says agent-session 1.0 keeps ONE
representation, that it is ACP's, and that the snake_case explicit-false shape
is "the contract defect to remove, not a second representation to name". So
this implementation DELETES the second constant rather than keeping it.

Revalidated: the pinned SDK's FileSystemCapabilities members are optional, so
an empty `fs` is a complete expression of "no filesystem capability" and an
explicit false was never needed to say it.

3. TWO SUPERSEDED ASSERTIONS, MARKED WHERE THEY STOOD

  model, `..._inventory_matches_the_vendored_declaration`
      asserted every `fs` member was present and False -- the removed shape,
      stated as a property. It asserts the empty object now.
  v12, `the ACP wire shape is not the durable profile summary`
      asserted the profile's document was REFUSED as an advertisement,
      because the two representations differed. The ruling removed the
      second, so the case is INVERTED: renamed `W641: the profile persists
      the SAME document the relay sends`, and it now asserts the profile's
      document validates, negotiates, and comes back as an OWNED copy --
      because one representation is not one object.


4. WHAT DID NOT CHANGE, DELIBERATELY

The exact minimal-capability POLICY. Withholding is still total; `session` is
still stable and still not advertised; the eight client methods are still
denied. The ruling corrected which document expresses that policy, not the
policy, and the cases that carry it are untouched.
