# Where v12 is hardest to maintain

Assessment of committed source **b5abf7983fb07eb3a8268f2d4559a04de9c0f1bd**. The most consequential observed problems are at transitions between components that each have a valid local view. A worker could enforce its image layout while the launcher omitted the layout selection. A manager could finish and retain a verified edit while a launcher waiting on its exchange reported failure. The most useful first changes give consumers the same observable contract as the component that owns the transition.
